# HD2D 制作任务与验收清单

日期：2026-09-16。配套 [GDD.md](GDD.md) v0.4 与 [P1_SCOPE_BASELINE.md](P1_SCOPE_BASELINE.md) v1.1。原清单为完整 P1 待实施计划；本次已落地部分 P0 战斗试炼，已完成项与验证边界见 [DEMO_STATUS.md](DEMO_STATUS.md)，不表示对应 P1 工作包全部完成。A 组已按基线 v1.1 的苏晓按键与技能集重排。

## 1. 推荐执行顺序

战斗修正（输入重排 → 拼刀替换 → 动作补齐）→ 数据边界 → 存档与世界流程 → 世界任务 → 结算与主城成长 → 视听与试玩。

A 组内部顺序固定：A01 先换键，A05 再删按住防御改成拼刀，之后 A06 双枪、A08 青钢影逐个验证；双枪、炸弹与青钢影不得同时开工。灰盒地图与 UI 草图可以穿插进行；批量美术等动作、镜头和地图尺度稳定后再制作。

## 2. P0 完成定义

- 当前测试场包含玩家、近战敌人和一个测试远程威胁，不需完整关卡。
- 沿用用户现有自建角色；鼠标点击定向三段轻击、剃、HP/MP 与试炼重试形成连续体验。
- 按键按基线 v1.1 重排：左键攻击、右键双枪、Q 猎魔、E 傲歌、R 刀芒、F 环断、T 影刺、Left-Shift 剃、数字 1 炸弹、数字 2 药剂、V 交互、Esc 面板；拼刀不占按键。
- P0 只要求已有动作换到新键位后仍可玩（A01、A05）；双枪、炸弹、青钢影等新系统属于 P1 战斗包（A06～A12），不阻塞 P0 试玩。
- 开发模式可显示攻击范围、动作阶段和无敌窗口；正式 HUD 默认隐藏调试信息。
- 操作和伤害反馈通过后，再投入正式存档、复杂任务与完整 UI。

P0 不要求补齐所有美术，不要求三资源经济、天赋树和主城。

P1 开始后，每个新增需求必须先通过范围基线的变更门禁；无法指出被替换工作量的新增项不进入 P1。

## 3. 高风险规则验证

| 检查 | 方法 | 必须证明 |
|---|---|---|
| 连击/重复命中 | 固定时间步模拟 + 实机观察 | 三段可达，一个攻击 ID 不重复伤害 |
| 护盾与伤害链 | 小型规则测试 | 物理/真实/灵魂按正确抗性与护盾路径计算 |
| 商店事务 | 余额不足、重复操作、中断注入 | 不负币、不免费发货、不只扣款 |
| 结算幂等 | 同一结算 ID 重复提交 | 所有资源最多增加一次 |
| 死亡与救援重启 | 有币/无币致死、提交中断后加载 | 有币只扣一枚并保档、收益只折损一次；无币封存 |
| 救援收益边界 | 零收益、历史存款、任务未完成、超时 | 历史资产不扣，未完成奖励不发放，处决不绕过逃脱币 |
| 鼠标方向 | 边移动边点击各方向、连段改向、点击 UI/脚下 | 攻击跟随点击，缓冲保留方向，不误攻击 |
| 拼刀判定 | 双方不同出手时机、有效帧重叠与错开、远程同时命中、冷却内重复触发 | 只在近战窗口触发，双方都不结算伤害，冷却内不能连刷 |
| 旧键位残留 | 全键位人工跑一遍（右键、E、Q、Tab、V、Esc、数字 1/2） | 右键不格挡、E 不斩击、Q 不喝药、Tab 不弹面板、V 交互生效、数字 1/2 各司其职 |
| 影刺前置 | 空放、刺击未命中、标记过期、目标已死亡 | 无标记不扣法力无特效，有标记必定生效一次 |
| 青钢影真实伤害 | 对能量敌人、对无能量敌人、法力耗尽、连续开关 | 能量敌人吃真实伤害，无能量敌人只吃物理伤害，MP<1% 强制关闭 |
| 法力经济 | 击杀两类敌人、长时间保持猎魔 | 纯肉体敌人不回法力，无法靠开关猎魔刷法力 |
| 弹药与炸弹库存 | 打空弹药、库存耗尽、试炼重试 | 库存不回涨，重试不改变正式资源 |
| 护盾上限 | 持续挂盾、打满吸收量、超时与主动撤销 | 不能无限常驻，超时自动破碎，破盾有短硬直 |
| 抽卡恢复 | 开启前后保存并重启 | 同一卡实例结果相同 |
| 临时限制 | 入场、退出、中断恢复 | 临时属性和效果不泄漏到主城或其他世界 |
| 导航与前景 | 人工跑图 | 无隔墙攻击、不可达死角与危险遮挡 |
| 玩家理解 | 陌生玩家观察 | 能说明死亡原因、撤离条件、入账时机 |

测试围绕实际规则风险设计，不为纯文案或低风险布局新增重复测试。本轮只更新规划，上述功能检查尚未执行。

## 4. 阶段停止条件

- 战斗必须靠堆药或整体降伤害才能玩：先修前摇、状态与反馈，暂停经济扩展。
- 存档恢复不可靠：只用试炼或一次性测试角色，暂不进行正式永久死亡试玩。
- 第一世界路线选择无意义：修正现有敌人、情报与收益，不先增加第二世界。
- 美术超预算：先复用动作与模块，不删攻击预警和命中反馈。
- P1 未通过：不展开多人、复杂从者、高阶品质和团队系统。

## 5. P1 范围锁定

用户明确暂缓人员投入、预算排期与对外题材/名称。本清单保留技术依赖，不预设开发人数或日期。逃脱币价格与不可拆分战利品折损在经济实现前细化。

禁止新增的完整列表见 [P1_SCOPE_BASELINE.md](P1_SCOPE_BASELINE.md)。包括血气奥义、复杂异常、程序地图、随机词缀、高阶强化、晋升/强制猎杀、魅力幸运效果、长剧情、主城美化、图鉴、高级试炼、单局临时 Build、从者和联网 PVP。

每次将一项重新纳入范围时，写明它改善哪一个玩家决策、复用哪些系统、增加多少内容与验证成本。

本次已按基线 v1.1 把 A 组从「五项操作」重排为「按键映射 + 拼刀 + 双枪 / 炸弹 / 青钢影 / 傲歌 / 刀芒 / 环断 / 影刺」，变更账目见 [P1_SCOPE_BASELINE.md](P1_SCOPE_BASELINE.md) 第 6 节。使徒之眼与吞噬之核保持后置：Tab 与鼠标中键在 P1 内不绑定任何功能，也不制作入口、面板或数据。执行顺序按 A01 → A05 → A06 → A08 推进，E01 的新增动作资产不得提前批量制作。
