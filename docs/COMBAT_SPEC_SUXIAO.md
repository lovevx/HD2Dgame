# 苏晓 Demo｜最常用战斗方式与动作精简汇总

版本：v1.1 · 日期：2026-09-16 · 状态：按键与范围已确认，落地细则以 P1 基线为准

本文汇总“实战高频、核心机制优先，砍掉冷门与演出向动作”的战斗设计，作为按键映射、动作清单、连招逻辑与机制约束的对照依据。本文只做整理，不修改游戏代码，也不代表已实现功能。P1 的范围裁决与变更账目见 [P1_SCOPE_BASELINE.md](P1_SCOPE_BASELINE.md) v1.1；实施任务见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) A 组。

角色定位：**猎杀型刀战角色**。优先侦查拉扯、消耗敌人能量，抓住破绽近身爆发；法力是核心资源，青钢影靠燃烧敌方能量打真实伤害。

与 [GDD.md](GDD.md) 第 5 节、[P1_SCOPE_BASELINE.md](P1_SCOPE_BASELINE.md) 的差异与待确认项见第 8 节。

## 1. 标准完整战斗循环

```text
侦查评估 → 远程骚扰消耗敌人能量 → 拉扯走位规避伤害 → 寻找进攻窗口 → 剃突进贴脸
开启青钢影猎魔 → 近战输出，可穿插刀术招式 → 法力不足立刻关闭青钢影后撤
危险时刻释放傲歌护盾；击杀能量敌人靠噬灵者回复法力；必要时使用炼金炸弹。
```

核心特点：**不无脑冲脸硬刚，忌讳站桩对砍；法力枯竭战斗力暴跌；遇到高威胁优先撤退，不是死磕到底。**

## 2. 按键与功能映射

| 按键 | 功能说明 |
|---|---|
| W/A/S/D | 移动、战斗奔跑、走位拉扯 |
| 鼠标左键 | 近战：正手劈砍 / 反手突刺（普通平 A 连招） |
| 鼠标右键 | 黑白双枪，远程物理骚扰输出（弹药有限） |
| Q     | 青钢影・猎魔：开启 / 关闭，近战燃烧敌人能量造成真实伤害；法力低于 1% 自动强制关闭 |
| E      | 青钢影・傲歌：生成 / 撤销能量护盾，消耗法力；护盾有耐久与最大存活时限 |
| R | 刀芒：远程刀气，中距离消耗手段，**无真实伤害** |
| F | 环断：环形范围刀芒，对付复数包围敌人 |
| T | 影刺：**必须刀刃已经刺入敌人才可释放**，敌人体内爆发青钢影尖刺；空放无效 |

## 3. 高频战斗动作清单

### 3.1 基础移动动作（循环）

1. **战斗待机 Idle_Battle**：压低重心持刀戒备，右手握斩龙闪刀斜向下，紧盯目标；少量呼吸循环。
2. **战斗奔跑 Run_Battle**：重心压低，上半身稳定少晃动，下半身迈步；黑色风衣向后飘动；随时可转攻击、转剃位移。

### 3.2 近战持刀攻击（最高频）

1. **正手劈砍（平 A）**：腰胯发力自上而下斜劈，最多 3 段连击；青钢影开启时刀刃缠绕暗红烟气。
2. **反手刺击**：反手握刀向前穿刺，**影刺的前置关键动作**。
3. **拼刀格挡**：替代原“刀格挡”。双方近战攻击的有效帧重叠时触发，双方本次攻击都不结算伤害，敌人被弹开并进入短硬直；纯物理对拼，不耗法力，不占用按键。
4. **收刀归鞘**：战斗间隙后撤收刀，重置攻击节奏。

### 3.3 刀术招式

1. **刀芒 R**：短促挥刀释放远程红色刀气，中距离消耗敌人，没有真实伤害。
2. **环断 F**：原地旋转挥刀，环形向外爆发刀芒，清理包围的复数敌人，法力消耗偏高。
3. **影刺 T**：前置条件为刺击命中敌人；手部轻微震颤，能量在敌人身体内部爆发尖刺；**苏晓本体没有大幅度挥砍动作，特效主要在敌人身上，禁止空放**。

### 3.4 青钢影能量动作

1. **猎魔（Q 开启 / 关闭）**：开启时刀身缠绕暗红色流动烟气；关闭时烟气收回；持续每分钟消耗大量法力；法力过低强制关闭。
2. **傲歌护盾（E）**：抬手意念生成暗红色水晶护盾；可挡正面与头顶攻击；可主动撤销；超时自动破碎。

### 3.5 位移与闪避（实战高频）

1. **剃 Shift**：地面蓄力爆发，短距离高速向前 / 侧向 / 向后位移；原地留残影；落地立刻回到战斗戒备姿态；**必须踩地面，空中不能释放，带冷却，纯肉体体术，无能量特效**。

补充：不做复杂 S 形小碎步机动（开发成本高），Demo 用「剃 + 奔跑走位」替代实现拉扯闪避效果。

### 3.6 道具动作

1. **投掷炼金炸弹【1 键】**：抬手取出炸弹投掷；可远抛输出，近距离放置预埋陷阱；踩到触发爆炸，库存有限。
2. **双枪射击【鼠标右键】**：双手举枪射击，仅物理骚扰输出，弹药有限。
3. **使徒之眼【Tab】**：头部微微偏转，侦查眼球飞出悬浮，敌人头顶生成威胁光点。**P1 后置，暂不制作。**

### 3.7 特殊大招（可选实现，高风险）

**吞噬之核（鼠标中键长按）**：左手贴住敌人持续读条 2.5 秒，期间不能移动；被攻击直接打断；读条成功吸收敌人能量回复法力；判定失败触发狂暴，敌我不分。

### 3.8 受击状态

1. **轻伤受击 Hurt_Light**：被击中身体踉跄短硬直，马上恢复战斗姿态，不会长时间倒地。
2. **重创硬直 Hurt_Heavy**：承受强力打击，单膝跪地 1～2 秒硬直；可开护盾防御，无法攻击。
3. **法力枯竭状态**：法力低于 1%，青钢影强制关闭，刀身上暗红烟气瞬间消散，转为拉扯防守。

## 4. 高频实战连招（可作 AI 逻辑，也可供玩家摸索）

**连招 1｜标准起手，打能量型敌人**

```text
Tab 开启侦查评估威胁 → 右键双枪 / R 刀芒远程消耗敌人能量 → Shift 剃突进贴脸
→ Q 开启青钢影猎魔 → 左键平 A / 反手刺击刺入敌人 → T 释放影刺爆发伤害
危险时按 E 开傲歌护盾；法力不足时 Q 关闭猎魔，Shift 剃后撤拉开距离。
```

P1 中使徒之眼后置，起手侦查由玩家观察与直感承担；其余步骤可直接作为 AI 逻辑。

**连招 2｜被敌人包围**

```text
E 开启护盾扛一轮伤害 → F 环断范围斩击清包围敌人 → Shift 剃向后拉开距离，重新拉扯。
```

**连招 3｜陷阱伏击打法**

```text
数字 1 预埋炼金炸弹在地面 → 奔跑拉扯把敌人引诱到陷阱区域 → 炸弹爆炸后，剃突进近身输出。
```

**连招 4｜对付无能量肉体敌人（青钢影真实伤害失效）**

```text
关闭青钢影，只依靠刀术、炸弹、双枪打物理伤害；不要开猎魔浪费法力。
```

## 5. Demo 核心约束（防止机制崩坏）

1. **青钢影真实伤害只对拥有能量（查克拉、RC 细胞等）的敌人生效**；完全无能量的肉体敌人只受到普通物理伤害。
2. **影刺不能空放**，必须刺击命中敌人才允许释放。
3. **剃必须在地面释放**，空中释放判定失败，有冷却，不能无限闪烁。
4. **法力是第一资源**，没有大量回蓝药剂；法力主要来源是击杀拥有能量的敌人（噬灵者天赋）；击杀纯肉体敌人不回复法力。
5. **傲歌护盾有最大法力消耗上限与存在时间上限**，不能无限常驻护盾。
6. **使徒之眼看到黑色威胁光点**时，逻辑上提示玩家优先撤退，不鼓励硬刚（P1 后置，威胁提示暂由直感承担）。

## 6. 可直接舍弃不做的动作

1. 蹬墙借力弹跳、复杂锁技断头台缠斗；
2. 大量表演向小动作（甩刀收血等，可后期迭代再加）；
3. 复杂 S 形碎步侧身闪避（用剃代替功能）。

## 7. 落地决定与后置项

以下为 2026-09-16 的确认结果，细则与变更账目以 [P1_SCOPE_BASELINE.md](P1_SCOPE_BASELINE.md) v1.1 为准，实施任务见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) A 组。

1. **引擎**：原文标注“适配 Unity / HD2D”，当前工程为 Godot 4.7（`project.godot`，Forward Plus + Jolt，1920×1080）。落地技术栈以 Godot 为准。
2. **键位**：以本文第 2 节表格为准。原「右键按住格挡」改为拼刀格挡（无按键），MP 吸收格挡与 guard 停帧表现删除；药剂由 Q 移到数字 2，面板由 Tab 移到 Esc，交互由 E 移到 V。剃保持 Left-Shift。
3. **范围**：进 P1 的新增系统为青钢影・猎魔（含敌人能量属性、真实伤害、噬灵者回蓝）、双枪与炼金炸弹；刀芒、环断、影刺、傲歌护盾与三段连击一并实装。P1 战斗内容为净增，变更账目与执行顺序见基线第 6 节。
4. **后置**：使徒之眼（Tab 空置）与吞噬之核（鼠标中键空置）在 P1 不制作玩法、数值、表现与 UI，原文标注的「可选做」按后置处理。
5. **伤害类型**：P1 由「只投放物理伤害」改为「物理伤害 + 对拥有能量敌人的真实伤害」；灵魂伤害仍只保留枚举、事件字段与规则测试接口。
6. **剃**：文中要求（踩地、空中不可释放、有冷却、落地回戒备）与 GDD 已定义的 0.15 秒蓄力无敌 / 0.55 秒位移 / 2.2 秒冷却一致；“原地留残影”“无能量特效”为表现层要求。
7. **影刺前置**：反手刺击命中后记录“刺入”标记，无标记时空放无效且不扣法力；标记时限与是否持续到目标死亡在实现前确定。
8. **待校准初值**：拼刀窗口、弹开距离、硬直与冷却，以及双枪、炼金炸弹、青钢影、傲歌护盾、刀芒、环断、影刺的伤害与法力消耗均为初值，需试玩校准；[GDD.md](GDD.md) 第 5.1 节已按此更新。
9. **特效配色（2026-09-17）**：青钢影相关能量表现统一改为**暗红色系**（刀身烟气、刀气、水晶护盾），规避原作标志性蓝色视觉的近似版权风险；剃为纯肉体体术，无能量特效。渲染进程已同步：护盾表现（player.gd）改暗红。
