# 《轮回乐园》HD-2D 肉鸽动作 · 游戏设计方案（GDD）

> 基于《轮回乐园》原著提取的游戏化设定，剥离叙事，落实为可实现的垂直切片设计。
> 引擎：Godot 4.7（Forward Plus，Jolt）· 视角：俯视 3D（HD-2D）。

---

## 1. 定位与设计支柱

**一句话**：HD-2D **肉鸽动作**游戏——主城 + 副本 + 死亡惩罚 + 等价交换构成核心循环。

本 IP 的"主城 / 副本 / 死亡惩罚 / 等价交换"结构天然匹配成熟肉鸽循环：
`主城强化 → 进副本 → 任务/战斗/猎杀 → 结算资源 → 死亡惩罚 → 回城兑换永久成长`。

**三个差异卖点（爽感来源）**：
1. **等价交换**：变强必有代价，强化有失败风险。
2. **半提示系统**：乐园只给权限内情报，敌人弱点需玩家自行侦查/估算。
3. **直感机制**：被动预警只提示"危险体感"，不标方位，牵引走位博弈。

**本期做减法**：不做公会、从者、多乐园 PVP、天赋树。首版只做**"一枪一局"肉鸽闭环**。

---

## 2. 垂直切片范围

### 做
- 主城（强化大厅 / 商店 / 试炼场）＋ 副本传送门
- 一个固定副本（入口 → 普通怪 → 精英 → Boss → 结算点）
- 近战战斗（连段普攻 / 闪避 / 攻击判定 / 敌我击退）
- 双资源：乐园币（通用）＋ 灵魂结晶（高阶稀缺）
- 死亡惩罚（掉 50% 乐园币回城）
- 半提示（血缘估算条）＋ 直感预警雏形

### 不做（本切片）
- 随机地图生成、从者/召唤物、天赋/称号、技能树、任务类型（仅留"猎杀目标"线）
- 多乐园 PVP、世界之源兑换、世界争夺战

## 3. 系统规格

### 3.1 战斗
- 近战：轻击连段（前 2 段普攻＋末段重劈）、闪避（短位移＋短暂无敌帧）、短距离 hitbox 判定。
- 敌人：普通怪（近身追击＋普攻）/ 精英（多阶段＋霸体）。受击击退、死亡动画、掉落。
- 手感优先级：命中停顿、击退、受击抖动 > 数值。

### 3.2 属性与数值层
- 六维：力量 / 敏捷 / 体力 / 智力 / 魅力 / 幸运（成人普通值 5）。
- 首版接入战斗的属性：力量（攻击）、体力（HP/防御）、敏捷（攻速/闪避）；其余仅面板显示。
- 衍生：生命值（体力/装备/被动）、法力值 = 智力 × 10。

### 3.3 资源闭环（等价交换核心）
- **乐园币**：击杀掉落＋副本结算 → 商店买药、武器强化。
- **灵魂结晶**：精英/Boss 掉落，强化高等级必需，稀缺感来源。
- **强化规则**：武器 +0→+N，等级越高成功率越低；**失败掉阶，可能损毁**（等价交换具象化）。

### 3.4 死亡与惩罚（控制挫败感）
- 副本内死亡 → 掉落 50% 乐园币 → 返回主城 → 副本进度重置。
- **首版不做永久删档/处决**。

### 3.5 半提示 & 直感
- 敌人不显示精确血条，改为**血缘估算条**（模糊刻度＋颜色区间）。
- Boss/精英触发**直感预警**：屏幕边缘单位方向不明的"危险体感"，不标注坐标。

### 3.6 乐园提示文本
- 统一蓝色提示条样式，作为唯一权威判定来源（击杀 / 结算 / 惩罚均走它）。

## 4. Godot 技术架构

```
autoload/
  game_state.gd      # 跨场景存档：属性、资源、强化等级（Resource 序列化）
  world_flow.gd      # 场景切换：主城 <-> 副本、结算、死亡回调
scenes/
  hub/               # 主城：强化大厅 / 商店 / 试炼场 + 副本传送门
  dungeon/           # 复用 main 的镜头/光照，做成副本房间
  ui/                # 血条、蓝色乐园提示、结算面板、直感预警
scripts/
  combat/            # 连段 / 闪避 / hitbox、敌人 AI、击退、伤害
  entities/
```

- 场景切换：`ui://` 透明渐变过渡。
- 现有 `player.gd` 的俯视 `Vector3` 移动层保留，不重写。

## 5. 实施步骤（每步可跑可验收）

1. **战斗核心**：连段普攻＋闪避＋击退＋敌人 AI＋击杀掉币（把 main 做成可打怪战斗场）。
2. **数值数据层**：六维 / 生命法力 / 双资源 ＋ `GameState` autoload 持久化。
3. **副本场景**：固定房间（入口→普通怪→精英→Boss→结算点）。
4. **死亡与结算**：死亡掉币回城、结算面板、乐园提示文本。
5. **主城场景**：强化大厅（失败风险）＋商店＋试炼场木桩＋传送门。
6. **半提示 / 直感收尾**：血缘估算条＋直感预警。

---

## 6. 验收标准

- 玩家可从主城进副本、战斗、击杀掉落资源、开门回城。
- 强化存在"失败掉阶 / 可能损毁"的代价反馈。
- 死亡损失 50% 乐园币并回城，资源循环成立。
- 敌人血条为估算式；Boss 触发直感预警；乐园提示为蓝色权威文本。
