# P0 Demo 原型交付

本次优先完成可反复试玩的战斗试炼，复用现有黑衣剑士素材，不新增付费美术生成。

## Demo 内容优先级

1. **已完成：战斗基础**。鼠标左键点击方向攻击、三段连击、0.15 秒输入缓冲、0.12 秒前摇后单次命中；移动不覆盖出手方向。左 Shift 剃（六式・剃）：蓄力下蹲 0.15 秒（此段无敌），随后瞬间满速爆发，0.55 秒内位移约 6.5 米，末段骤停，冷却 2.2 秒。
2. **已完成：可读反馈**。HP/MP、敌人血量、红色落点预警、受击亮光、晶体防御球、操作提示。状态栏含药剂、剃与斩击的冷却（可用显示“就绪”，冷却中显示剩余秒数），文字带深色描边，在港口明亮石板与试炼暗地面上都读得清。
3. **已完成：试炼闭环**。开始说明 → 两轮固定遭遇（近战与远程落点威胁）→ 胜利或死亡面板 → 一键重试。试炼不修改正式货币、任务和存档。
4. **已完成：补充操作（下为 P0 重排前口径）**。右键按住防御（持续消耗 MP，伤害先扣 MP，溢出扣 HP）；E 面向技法斩击（25 MP / 4 秒冷却）；Q 药剂（每局 2 瓶，各恢复 45 HP）。**换键后现值为：右键 = 副手燧发枪射击、E = 青钢影・傲歌护盾（14 MP / 冷却 8 秒 / 持续 5 秒）、Q = 青钢影・猎魔；药剂 45 HP 在非战役仍适用，战役模式改为回最大生命 40% ÷ 本次使用次数。** 剃的表现已接入：半透明灰色残影、蓄力与落地尘土、破空气流，以及踩地/破空/落地三段音效。
5. **暂缓：完整 P1**。主城、正式港区地图、任务情报、装备成长、账户/角色/世界存档、逃脱币救援、永久死亡和事务结算。

这是 P0 白盒试炼，不是 P1 已完成。敌人使用占位胶囊，远程威胁是锁定落点攻击，尚无弹道、Boss、韧性/硬直或完整伤害类型系统；音效目前只有剃的三段动作音。

## 启动

在 Godot 打开项目后按 F6 运行 `scenes/main/main.tscn`，或 F5 运行主场景。点击“开始试炼”。WASD 移动，左键朝鼠标斩击（单段斜劈）；Space 剃；右键副手燧发枪，Q 猎魔，K 傲歌，E 直踢，R 刀芒，F 环断，T 影刺；1 炼金炸弹，2 药剂。中键拖动取景，滚轮推拉镜头。

## 验证

- Godot 4.7.2 headless 主场景启动检查。
- `tools/validate_demo.gd`：前摇无伤害、有效帧命中、单次命中、二/三段可达、盾溢出伤害、无敌、重置、两轮推进、胜败重试、正式货币隔离，输出 `P0_SMOKE: PASS`。
- `tools/validate_player_visual.gd`：四方向移动与镜像、攻击选择与镜像、剃的按键绑定/蓄力不动/爆发满速/位移距离/冷却拦截/左右镜像、残影位置与透明度、尘土与气流开关、三段音效挂载、格挡停帧、重生清锁，输出 `PLAYER_VISUAL_CHECKS: PASS`。
- 同一验证脚本通过 D3D12 / RTX 3060 Laptop 实际渲染并保存 `docs/demo_preview.png`，已检查画面。
- 实际鼠标手感、不同分辨率和长时间平衡性尚未人工完整试玩。

运行规则检查：Godot 可执行文件 `--headless --path E:/godotproject/hd-2d --script tools/validate_demo.gd`。加 `-- --capture` 并移除 `--headless` 可重新生成预览。
