## 一、系统总述

### 1.1 核心设计思想

1. **双装备体系**
   - 【乐园公证装备】◻：经轮回乐园烙印认证，可跨世界带回乐园；有完整评分、耐久、装备需求、正式提示文本。
   - 【衍生世界本土装备】◻：剧情世界原生装备，**世界结束后强制销毁，不能带出副本**；部分可临时使用，无乐园评分；部分可在本世界内改造。
   - 标注：✔ 已有雏形——`export` 字段即公证/本土的判定；结算按 export 清理（settle_trial）。

   > 例子：破旧燧发枪（海贼王本土，不能带出）；斩龙闪（乐园公证，可跨世界携带）。

2. **评分≠一切**：乐园评分是标准化参考，部分特殊装备/剧情道具/配件存在**超评分现象**；负面诅咒、代价效果**不计入正向评分**。
3. **耐久度机制** ▣：实体装备拥有耐久，归 0 损毁；部分装备耐久**上限永久损耗**（严重破坏后即便修复上限也降低）。
4. **装备需求门槛** ◻：力量/敏捷/体力/智力/特殊条件（身份、血统、限定）；不满足强行穿戴触发惩罚（属性降低、持续扣血、效果无效、装备崩坏）。
5. **储蓄空间（烙印背包）** ✔：即现有 `campaign.bag`；装备/材料/宝箱占空间；微型首饰/配件占据极小。

### 1.2 物品 / 装备五大类

| 分类 | 说明 | 典型例子 | 现状 |
|---|---|---|---|
| 🔹可穿戴装备 | 占装备位：武器、护甲、首饰、护臂、披风等 | 斩龙闪、亡妻的项坠、王者御尊护臂 | ✔ 部分 |
| 🔹配件 | **不占标准装备位**，可镶嵌/改造到装备上，单独不能生效 | 拉米尔使徒核心、宝石、芯片 | ▣ |
| 🔹消耗品 | 一次性使用后消失：药剂、炸弹、卷轴、子弹 | 初级炼金秘药、炼金炸弹 | ✔ 药剂/陷阱 |
| 🔹材料类 | 锻造/改造/炼金/任务提交；分普通、精英、稀有、淡金 | 虎爪、灵魂结晶、柱间细胞、尾兽之血 | ✔ 基础 |
| 🔹特殊剧情道具 | 宝箱、任务物品、信物；大多不能穿戴，部分世界限定 | 绿色宝箱、虎齿、晓戒指、引荐信 | ✔ |

> 注意：宝箱属于特殊剧情道具，本体占背包格；开启后宝箱消失，产出物按自身类别归类。✔ 已实现（CHESTS + open_chest）。

## 二、品质与乐园评分规则

品质从低到高（部分特殊装备溢出评分上限）：

| 品质 | 评分区间 | 说明 | 代表物品 | 现状 |
|---|---|---|---|---|
| 白色 | 1-10 | 普通；白色·稀有 = 满评分 10，带特殊被动 | 斩龙闪（白·稀 10）、亡妻的项坠（8） | ✔ 文本标注 |
| 绿色 | 10-30 | 精英掉落/精英宝箱产出，基础属性明显更高 | 虎爪（16） | ✔ 文本标注 |
| 蓝色 | 30-100 | 优秀装备，多世界精英 BOSS、高难度宝箱 | 库因克（喰种刀） | ▣ |
| 紫色 | 100-260 | 史诗装备，乐园锻造、高难度世界 BOSS | 1 号药剂（柱间细胞，紫 109） | ▣ |
| 淡金色 | 260-310 | 稀有强力装备/配件，极难获取，部分有代价 | 拉米尔使徒核心（296）、原始柱间细胞（305）、使徒之眼（300） | ▣ |

> ⚠ 字段落地：现品质只写在 `name` 文本里（如 "白10稀有"），需拆出结构化 `quality` 字段（品质 + 评分两个值）。

**特殊品类（1000 章内出现）**

1. **成长型装备**：吞噬材料/敌人精华提升品质与属性，有成长进度条；斩龙闪靠【至尊锋刃】吞噬武器提升品质。✔ 概念已定（§十三）。
2. **厄运物 / 原罪物**：强大能力 + 恶性诅咒/代价；评分浮动，风险远高于收益。▣
3. **霸主级 / 世界级**：1000 章后大量出现，本次策划不纳入。

**重要限制**

1. 本土剧情装备**没有乐园评分**；再强离世界即消失。
2. 配件也有品质与评分，影响改造后成品装备的最终评分。
3. 淡金色物品极难获取，很多是配件/材料，不一定是武器护甲。

### 4.1 ✅ 属性词条字段全集（已拍板）

| 词条键 | 含义 | 结算链路落点 |
|---|---|---|
| str / agi / con / int / cha / luk | 六维直接词条（**cha/luk 进词条可穿戴**） | 作战六维累加 |
| attack | 武器攻击 | ①原始攻击 |
| max_hp / max_mp | 上限词条 | 最大HP / 最大MP |

- 不写回裸装六维、反复装卸不叠加（沿 §2.2）；词条数量/数值范围由各品质物品表定义。

### 4.2 ✅ 六维 · 属性演算模块（三层架构，已拍板）

**分层落位**

| 层 | 内容 |
|---|---|
| 数据层·存档 | 仅裸装六维 `attributes` + `attr_points`；**作战属性、肉体系数、护甲减免、出售价、分解产出一律不落档**（实时算，防脏数据） |
| 数据层·静态表 | 肉体修正系数表 CON_HIT_TABLE、强化系数 K_str、品质 Q 表、击杀扣耐表（全部查表，禁硬编码） |
| 逻辑层 | 属性演算子模块：`作战 = 裸装 + 装备词条 + buff容器`，派生公式集中一处 |
| UI 层 | 面板只读显示作战属性，请求逻辑层结果；**UI 不写任何公式** |

**派生公式（集中存放）**
- attack：非战役 = 武器基础 7 + str；战役 = 武器区间中点 × 力量倍率 `str_atk_coef` × (1 + 0.1×刀术训练)（`player.gd`；不再是「武器 attack + str」）
- max_hp = 50 + con×10；max_mp = int×10；move_speed = 2.6 + (agi−5)×0.026（2026-09-19 降速；原 5.0 + ×0.05 已废弃）
- 肉体修正系数 `con_hit_factor`：**查表 ±2%/点（con=5 → 1.00）**，受击侧 ④ 步：

| con | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|
| 修正 | 0.98 | 1.00 | 1.02 | 1.04 | 1.06 | 1.08 | 1.10 |

- 护甲总减免 `armor_reduction` = Σ 各护甲装备 def_pct（含强化加成），进结算链路 ③。

**六维落点（10 步结算链路）**

| 六维 | 落点 |
|---|---|
| str | ①原始攻击（战役：武器区间中点 × 力量倍率 × 刀术训练；裸装口径为武器基础 7 + str） |
| con | 最大HP + ④受击肉体修正（查表） |
| int | 最大MP |
| agi | 移速（攻速/回避后续查表预留） |
| cha / luk | 词条可穿戴，不入伤害链路；luk 预留宝箱产出作用 |

**关键约束**：真实伤害跳过 ③护甲 ④肉体系数（只走护盾+全局 buff，独立分支）；预览与执行复用同一函数；buff 统一容器（类型/数值/剩余秒数/来源）。

### 4.3 ✅ 攻击区间浮动（已拍板）

**概念**
- `Weapon_Min` / `Weapon_Max` 静态配置（斩龙闪 5-16）；`Weapon_Range = Max − Min`。
- 强化**整体平移区间**：每 +1 同时提升 Min/Max（AttackAdd 按武器类型查表），**区间宽度恒定不变**。
- ❌ 禁止只加上限不动下限（强化越高抖动越离谱）。

**强化攻击增量表（查表）**

| 武器类型 | 每 +1 AttackAdd |
|---|---|
| 单手刀剑（斩龙闪类） | 1.5 |
| 重型双手武器 | 2.2 |
| 匕首 / 轻型武器 | 0.9 |
| 枪械类 | 1.2 |

例：斩龙闪 5-16：+1 → 6.5-17.5；+2 → 8.0-19.0；宽度恒为 11。

**伪随机算法（推荐方案 2：双 roll 取平均）**
- 单 roll 均匀随机（方案 1）不推荐：5-16 可能连续极值，跳动大。
- 双 roll：`Base_Weapon_Damage = (rand(Min,Max) + rand(Min,Max)) / 2` → 分布向中间集中，极端值概率降低，保留上下限可能；强化后分布形态不变。
- 可选进阶：幸运改变取值倾向——幸运≤1 取较小值、2-4 取平均值、≥5 取较大值（预留，见 §4.2 luk 落点）。

**接入链路（第一步：原始攻击输出）**

```
wMin = Weapon_Min + 强化等级 × AttackAdd[武器类型]
wMax = Weapon_Max + 强化等级 × AttackAdd[武器类型]
Base_Weapon_Damage = (rand(wMin,wMax) + rand(wMin,wMax)) / 2   // 含幸运倾向判定
原始攻击输出 = Base_Weapon_Damage × 力量攻击倍率(裸装查表) × 攻击标签倍率(偷袭/弱点等)
// 之后继续走原链路：护盾→护甲减免→肉体修正→全局减免→真实伤害分支
```

- 力量不足装备需求：力量倍率 × **0.6** 惩罚。
- 力量倍率是乘法，**不改变区间宽度**，只整体缩放随机结果。

**力量攻击倍率表（裸装力量查表）**

| 裸装力量 | 近战攻击倍率 |
|---|---|
| ≤5 | 1.00 |
| 6-10 | 1.10 |
| 11-18 | 1.22 |
| 19-30 | 1.35 |
| ≥31 | 1.45（锁死上限，防无限堆力量） |

> ⚠ 与现有 player.gd 衔接：现公式 `attack=(武器attack+str)×(1+0.1×训练)`；本方案改为「区间浮动 + 力量倍率」。刀术训练系数（×1+0.1×训练）建议并入 ① 原始攻击链路，保留成长性（待确认后实施）。

**UI 表现**
- 面板显示 `攻击：5-16`，强化后 `6.5-17.5`；不暴露内部 roll 值；只显示最终扣血百分比/参考虚拟数字。

**边界约束**
1. 强化只整体平移上下限，不扩大区间宽度。
2. 攻击区间只产出 Base_Weapon_Damage；力量/标签全部乘法缩放，不改 Min/Max。
3. 力量倍率上限锁死；不满足需求 ×0.6。
4. 统一用双 roll 取平均；**攻击区间不存档，每次攻击现场随机**。

**特殊武器**
- 枪械：同套区间（燧发枪 2-13、AttackAdd 1.2）+ 故障判定标签（概率攻击输出 ×0.3）。
- 能量/法术类武器：把力量替换为智力攻击倍率，区间逻辑完全复用。

## 五、装备产出途径

1. 📦 **宝箱掉落**（最主要）：产出按击杀目标等级、世界难度浮动；剧情主线 BOSS 不一定掉装备。
   - 白色宝箱：普通/精英敌人产出白色装备、乐园币、世界本土道具。
   - 绿色宝箱：精英生物 BOSS（科尔波山主人）出品绿装、高级材料、灵魂结晶。
2. 🗡️ **怪物直接拾取**：击杀直接拾取装备，分乐园公证/世界本土。
3. 🏪 **乐园交易市场 / 锻造铺**：乐园币、灵魂结晶、贡献点购买图纸/成品/材料。
4. ✨ **改造、锻造、炼金合成**：图纸+材料自造；配件改造装备（哈瓦呐之眼+拉米尔使徒核心→使徒之眼）。
5. 📜 **任务奖励**：主线/支线/猎杀任务、晓贡献点兑换、荣誉勋章在荣誉商店兑换。
6. 🧟 **吞噬成长**（成长武器专属）：吞噬同类武器积累成长值，满阈值品质晋升，继承原有效果，有概率获得被吞噬武器词条。

> 重要：**剧情世界商人售卖的绝大部分装备是本土限定，不能带回乐园。**

## 六、装备生命周期：强化、镶嵌、改造、耐久、分解、损毁

### 6.1 ✅ 强化系统（乐园强化机）——规则已定稿

**前置**：仅【乐园公证装备】可进强化机；本土世界装备无法强化。成长武器可强化；强化与品质晋升是**两套独立体系**。

**6.1.1 强化消耗公式（程序/表格直接用）**

| 变量 | 含义 |
|---|---|
| Q | 品质基础单次消耗（查表，不受评分小幅度浮动影响）：白1000 / 绿2500 / 蓝8000 / 紫12000 / 淡金30000 |
| K_grow | 成长装备倍率：普通 1.0 / 成长 1.5 |
| C_one | 单次强化消耗（点一次强化按钮的花费） |
| N | 目标强化等级（0→1 时 N=1；0→5 为 5 次操作） |
| P_n | 该档位成功率（0~1 小数；如 +0→+1 为 0.98） |

- 单次强化：**C_one = Q × K_grow**（同一件装备每一档花费固定，强化等级升高不涨价）
- 理论总消耗（不计失败重投）：**C_total = N × Q × K_grow**
- 期望总消耗（考虑失败重刷，数值平衡用）：**Total_expect = Q × K_grow × Σ(1/P_i)**，i = 1→N

例：斩龙闪（白色·稀有·成长）Q=1000、K_grow=1.5 → 单次 1500 币，+0→+5 理论 7500 币；亡妻项坠（白·普通）单次 1000 币。

**6.1.2 成功率与失败惩罚**

| 强化等级 | 基础成功率 | 失败惩罚 |
|---|---|---|
| +0 → +1 | 98% | 无惩罚，只扣本次乐园币 |
| +1 → +2 | 94% | 无惩罚 |
| +2 → +3 | 88% | 无惩罚 |
| +3 → +4 | 82% | 无惩罚 |
| +4 → +5 | 80% | 强化等级 -1 |
| +5 → +6 | 72% | -1~-2 |
| +6 → +7 | 65% | -1~-2 |
| +7 → +8 | 55% | 强化等级清零 |
| +8 → +9 | 40% | 强化等级清零 |
| +9 → +10 | 25% | 装备破损，无法普通修复 |
| +10 以上 | <10% | 装备直接损毁灭失 |

> 注：+0~+4 失败无惩罚（含 +4→+5 失败只 -1）；失败只损失本次费用，不提高下一次价格。
> ⚠ 简化版衔接（§6.3.4）：+9→+10、+10 以上的「装备破损 / 损毁灭失」耐久负面后果**已取消**——强化失败一律只损失乐园币，不扣耐久、装备不会消失；掉级惩罚保留。

**6.1.3 强化收益（每 +1）**

- 武器：攻击区间向上浮动 10%~15%；耐久上限 +3~5（§6.3.4）。
- 护甲（头/躯干/护臂/足/披风）：防御提升 12%；耐久上限 +4~7（§6.3.4）。
- 首饰：属性词条 +0.5~+1；无耐久属性，不受耐久影响。
- 成长装备：收益再上浮 20%（成本同步更高）。

**6.1.4 边界规则（避免违背原著）**

1. 灵魂结晶（小/中）可替代部分强化消耗；高强化等级才要求，属于额外门槛，不计入上述公式。
2. 本土世界装备不能进乐园强化机。
3. 宝箱开出的装备同样按品质评分收费，无优惠。
4. 淡金色强化极烧钱，符合"淡金色稀少昂贵"设定；本轮配套 GDD §7.4"首版强制作确定性优先"的落法待实施切片确认。

### 6.2 镶嵌（配件 / 宝石）▣
1. 装备必须有镶嵌槽才能装配件。
2. 配件可拆卸；部分高危配件拆卸直接损毁装备。
3. 区分两种模式：
   - **镶嵌**：配件附加效果，装备本体基础属性不变。
   - **改造**：配件彻底融合，本体品质与全部效果改写（使徒之眼案例）。

### 6.3 ✅ 耐久与修复（简化版）——规则已定稿

**用户拍板**：不做永久耐久扣除、不做装备灭失、不做复杂消耗。仅两个触发来源：**角色受伤 → 扣护甲耐久；击杀敌人 → 扣武器耐久**。

**装备耐久分类**
1. **武器类**（主/副武器）：仅【击杀敌人】触发耐久扣除；格挡/碰撞不再额外扣。
2. **护甲类**（头部、躯干、护臂、足部、披风）：仅【角色承受实际伤害】触发耐久扣除。
3. **首饰类**：无耐久属性，永不消耗，无需修理。
4. 乐园公证 / 本土装备都适用本简化规则；本土装备仍不能带回乐园修理。
5. 成长装备同样适用；品质晋升、强化依旧提升 `Dur_max` 上限。

**6.3.1 触发规则**

| 场景 | 扣耐规则 |
|---|---|
| 武器：击杀普通杂兵 | -1 |
| 武器：击杀精英敌人 | -3 |
| 武器：击杀 BOSS 级敌人 | -8 |
| 护甲：受到实际生命伤害（护盾吸收不计） | `ceil(本次实际伤害/10)`，最低 1，单次上限 5 |

说明：
- 多段攻击最后一段击杀**只扣 1 次**；技能/法术/天赋击杀**不扣武器耐久**（武器未参与）。
- 伤害被护盾/庇护完全吸收、角色不掉生命 → 护甲耐久**不扣**。

**6.3.2 状态（仅两种，无永久破损 / 无灭失）**
1. **正常**（cur > 0）：属性、被动、主动效果完整生效。
2. **严重受损**（cur = 0）：武器攻击区间减半、被动全失效（仍可挥刀）；护甲防御与词条全失效。
   ✅ 装备**不消失**、耐久上限保持不变、背包保留、可修复。

**6.3.3 修复（乐园锻造铺，仅乐园公证装备）**
- 唯一模式——普通修复：当前耐久直接恢复至 `Dur_max`。
- 成本公式：`修复费用 = Q × (Dur_max − Dur_cur) / Dur_max`；Q = 品质基础消耗（白1000/绿2500/蓝8000/紫12000/淡金30000）。
- 成长装备修复 × 1.5。
- 本土装备：乐园锻造铺拒绝受理，只能本世界 NPC 手工修复（剧情设定处理，无公式）。
- 例：斩龙闪（白 Q=1000，成长）`10/40` → 基础 = 1000×30/40 = 750，×1.5 = **1125 币**全修。

**6.3.4 强化与耐久联动（简化）**
- 成功 +1：武器耐久上限 +3~5；护甲 +4~7；首饰无耐久不受影响。
- **失败：仅损失乐园币，不扣耐久、无任何耐久负面**（移除旧"强化失败扣耐久/损毁"逻辑）。

**6.3.5 成长装备耐久特殊规则（斩龙闪）**
1. 吞噬武器、品质晋升 → `Dur_max` 提升。
2. 释放武器主动招式（影刺、环断）**不再额外扣耐久**。
3. 击杀照常扣武器耐久；修复消耗倍率保持 ×1.5。

**6.3.6 耐久 JSON 字段（简化版，追加进 §四 模板）**

```json
{
  "当前耐久": 10,
  "耐久上限": 40,
  "是否无耐久装备": false,
  "装备损毁状态": "正常",   // 枚举：正常 / 严重受损
  "成长装备耐久倍率": 1.5,
  "自我修复速率": 0        // 每小时恢复 X 点当前耐久；0 = 无自我修复
}
```

> 删除字段：`原生最大耐久上限`、永久破损、彻底灭失相关字段。

### 6.4 ✅ 装备分解 & 出售——规则已定稿

**适用对象**：仅【乐园公证装备】。本土装备不能带回乐园，无法乐园出售/分解，只能本世界丢弃或卖给世界 NPC（价格剧情设定，不走公式）。

**前置**：装备耐久为 0（严重受损）依然可出售/分解（仅被 F_dur 压低收益）；简化规则无灭失 / 永久破损，不存在无法处理的报废装备。

**6.4.1 概念**
1. **出售**：卖给乐园系统 → 乐园币，装备直接消失。
2. **分解**：交分解机 → 锻造材料，几乎不给乐园币。
3. 两者二选一，一件装备不能既卖又分。
4. 宝箱、配件、材料、消耗品有各自独立的出售/分解逻辑。
5. 强化等级影响产出；耐久只作修正系数，不直接废掉装备。

| 变量 | 含义 |
|---|---|
| Q | 品质基础值（白1000/绿2500/蓝8000/紫12000/淡金30000） |
| R_sell | 出售基准比例 0.4（乐园 4 折回收） |
| R_decomp | 分解产出基准系数 0.35 |
| K_str | 强化等级系数（见下） |
| F_dur | 耐久修正系数 = Dur_cur / Dur_max |
| K_grow | 成长装备系数：普通 1.0 / 成长 1.2（分解/出售产出略高） |

| 强化等级 | K_str | 强化等级 | K_str |
|---|---|---|---|
| +0 | 1.00 | +5 | 1.28 |
| +1 | 1.05 | +6 | 1.36 |
| +2 | 1.10 | +7 | 1.45 |
| +3 | 1.15 | +8 | 1.55 |
| +4 | 1.20 | +9 | 1.65 |
| | | +10 | 1.80 |

**6.4.2 系统出售（获取乐园币）**

`SaleCoin = Q × 0.4 × K_str × F_dur × K_grow`（**向下取整**）

- 乐园固定 4 折基准回收；耐久越低卖得越少，`F_dur=0`（严重受损）只能拿到 40% 基础售价。
- 强化越高售价越高；成长装备 ×1.2。
- 配件/消耗品/材料**不走本公式**（固定单价）。
- 淡金色部分特殊剧情装备【不可出售】：按钮置灰，提示"该物品禁止乐园回收"。
- 例1：斩龙闪（成长、+0、10/40）→ 1000×0.4×1.0×0.25×1.2 = **120 币**
- 例2：亡妻项坠（普通、+3、满耐）→ 1000×0.4×1.15×1.0×1.0 = **460 币**

**6.4.3 装备分解（产出锻造材料）**

`MaterialCount = ceil(Q ÷ 100 × 0.35 × K_str × F_dur × K_grow)`（材料**向上取整**）

| 装备品质 | 分解产出 |
|---|---|
| 白色 | 白色锻造材料 |
| 绿色 | 绿色锻造材料 |
| 蓝色 | 蓝色锻造材料 |
| 紫色 | 紫色锻造材料 |
| 淡金色 | 淡金色锻造材料 |

- 只产出**本品质基础材料**，不跳品质。
- 严重受损（耐久 0）依旧可分解，数量被 F_dur 压低。
- 强化越高材料越多；成长装备 ×1.2。
- 部分剧情/淡金色装备【禁止分解】：按钮置灰。
- 例：亡妻项坠（普通、+3、满耐）→ ceil(1000÷100×0.35×1.15×1.0×1.0) = ceil(4.025) = **5 个白色锻造材料**

**6.4.4 非装备物品的出售 / 分解**

| 类别 | 出售 | 分解 |
|---|---|---|
| 普通材料 | 可售，固定乐园币单价 | 不可分解 |
| 配件 | 普通配件可售；高危剧情配件禁售禁分（如拉米尔使徒核心），按钮灰；**不走装备公式，固定值写死在物品表** | 同左 |
| 消耗品（药剂/炸弹等） | 可售，折价回收 | 不可分解 |
| 宝箱 | 不能出售 | 不能分解，只能开启 |

> 控制字段：`can_sell: true/false`、`can_decompose: true/false` 决定按钮是否激活。

**6.4.5 本土衍生世界装备**
1. 无法带回乐园，不能在乐园出售/分解。
2. 本世界内：可卖给世界 NPC（价格由剧情设定，不使用数学公式）；或就地拆解获得少量世界本土材料，不能带入乐园。

**6.4.6 边界约束**
1. 出售、分解二选一；执行后装备直接消失，不可回退。
2. 严重受损（耐久 0）依旧可卖/分，只是收益被 F_dur 压低；无报废装备。
3. 强化越高收益越高，鼓励处理高强化淘汰装备。
4. 淡金、剧情类物品设禁售/禁分，保护剧情与数值平衡。
5. 乐园币一律向下取整；材料数量一律向上取整。

**6.4.7 数据库追加字段（进 §四 模板）**

```json
{
  "can_sell": true,
  "can_decompose": true,
  "sell_final_coin": 0,               // 缓存出售乐园币，UI 直接读取
  "decomp_material_type": "白色锻造材料",
  "decomp_material_num": 0            // 缓存分解产出材料数量
}
```

> ⚠ 原著"成长武器分解损失全部成长进度"被本次规则取代：成长装备分解/出售产出反向 ×1.2 提高；成长进度损失逻辑随成长系统未实现而搁置。

## 十三、【成长武器专属规则】以斩龙闪为范例 ✔ 概念定稿

## 十四、游戏化操作闭环（玩家完整流程）

```
击杀敌人 / 完成任务 → 获取【装备/宝箱/材料/配件】
→ 存入烙印储蓄空间
→ 打开宝箱（宝箱消失，获得产出）
→ 选择：穿戴 / 放入仓库 / 分解 / 改造 / 镶嵌配件 / 强化机强化
→ 穿戴校验：装备需求是否达标
    ✅ 达标：装备生效，占用装备位
    ❌ 不达标：拒绝穿戴，弹出惩罚提示
→ 战斗消耗耐久
→ 战后：修复装备 / 分解无用装备获取材料
→ 世界结束校验：清除全部【本世界限定】本土装备
```
