# 轮回乐园 · 单机底层系统与核心循环

版本：v0.3 · 2026-09-17 · 科尔波山猎虎纵向切片

本稿以 background/轮回乐园海贼王篇游戏化设定.docx 为核心循环依据。可玩范围从乐园契约、废品终点站到击杀科尔波山巨虎。当前主入口为 scenes/main/campaign.tscn（按存档装配原有地图），实际数值集中在 data/campaign.gd。历史 GDD 中全属性5、源点换属性点、灰潮港主线及未来技能，不覆盖本切片规则。

本次不制作现实世界、契约者社会、职工者生态、交易市场模拟或多人玩法。乐园保留与玩家成长有关的结算、储蓄空间、属性强化、补给、刀术训练、再次试炼入口，接入原灰潮港的商店、工坊、委托所、演武场与北侧世界入口。

## 1. 三层核心循环与本次截止点

- 微观：查看目标说明 → 装备/陷阱备战 → 战斗与闪避 → 击败目标 → V领取战利品 → C开箱和换装 → 恢复并前往下一区域。
- 中观：废品终点站 → 王都入口 → 侍卫总部 → 欢乐街 → 科尔波山巨虎 → 阶段试炼结算。
- 宏观：结算获得属性点/乐园币 → 乐园强化与补给 → 再次阶段试炼，保留成长并重新计算单世界噬灵者配额。

**阶段试炼是为验证闭环增加的游戏化规则，不代表完成原著海贼王世界。** 国王主线保持未完成；虎齿仅取得，不交付左大臣、不授予侍卫首领身份、不触发灭法传承。再次出发复用这五个地区，不增加后续剧情或新地图。显示试炼轮次，避免误以为推进下一卷。

## 2. 半数据化与战斗

生命对玩家、普通敌人和巨虎均显示百分比。内部仍使用HP数值进行碰撞伤害结算；血量归零死亡，原著任意要害即死暂不模拟。玩家生命低于10%时移动速度降至60%；敌人重伤仍由具体行为状态控制，不暗示所有目标都有同一套重伤规则。

本切片动作：左键方向三连、Shift闪避、F燧发枪、1火药陷阱、2恢复品。复用原战斗实现，但把“剃”理解为本阶段的短距离闪避；没有青钢影、刀芒、环断或法术。法力目前是长期成长资源，不承担攻击消耗。

伤害规则（原型定值，后续再调平衡）：

- 匕首基础攻击5，斩龙闪基础攻击16，加装备后力量；刀术训练每级乘加10%，最高3级。
- 三连倍率1 / 1.15 / 1.8；存在前摇、攻击范围、朝向与拼刀判定。
- 燧发枪6发/次试炼，单发35、间隔1.8秒、范围22米、窄锥形选最近目标，未命中也耗弹。
- 火药陷阱复用原炸弹实体：单个90伤害，半径4.5米，踩踏后0.35秒爆炸。科尔波山开战前可以投掷预埋。
- 巨虎800HP；65%狂暴、25%诈死，诈死仍存活；后方近战命中3次破坏后腿筋腱，步速降至60%、扑击速度降至65%。生命真正归零才掉落。

数值与原著武器区间分开：斩龙闪条目保留原著5~16攻击信息，原型采用区间上沿16，避免随机波动妨碍验证流程。燧发枪35点为原型伤害，不声称是原著数值。

普通流民与入队切磋不产永久法力；教官并未被剧情杀死。击败时在当前战斗显示预期法力增长，领取战利品后永久提交。单世界最多100，临近上限只发剩余额度；同ID不能重复计奖。再次完整试炼重置配额和目标ID，累计永久法力不重置。

本原型死亡使用检查点重试，未领取的本区域收益与消耗一并回滚，因此不允许通过反复阵亡保留击杀成长。

## 5. 装备与储蓄空间

固定8槽：武器、躯干、左护臂、右护臂、鞋、戒指、项链、勋章。一槽一个物品，换装覆盖槽位但不销毁原物；同名物品可堆叠，装备效果不随堆叠数量增长。

当前可装备：普通匕首、斩龙闪、亡妻的项坠。其余槽位保留为空。燧发枪是F键副武器，不挤占近战主手；道具不能误装入槽位。力量加成从裸装派生，不写回裸装，反复装备不会叠加。

| 物品 | 属性/身份 | 带出规则 |
|---|---|---|
| 普通匕首 | 开局近战武器 | 仅世界内 |
| 破旧燧发枪 | 白3，F键有限弹药 | 仅世界内 |
| 引荐信、侍卫凭证 | 地区推进依据 | 仅世界内 |
| 斩龙闪 | 白10稀有，主要装备成长锚点 | 可带出 |
| 亡妻的项坠 | 白8，力量+1 | 可带出 |
| 木天芷、火药陷阱 | 猎虎准备物资 | 仅世界内 |
| 虎齿 | 支线目标已取得，未交付 | 本次保留为切片战利品 |
| 虎爪、灵魂结晶、宝箱、恢复品 | 材料/消耗品 | 可带出 |

物品字段集中于配置表；结算按export字段清理，装备槽引用同步清理。白色评分1~10、绿色10~30为展示/价值约定，不自动转换战力。背包暂不施加重量和2m³装箱限制。

后续底层扩展设计：装备实例应带唯一ID、当前/最大耐久、装备需求、来源与绑定世界；武器/防具磨损、饰品无耐久。耐久为0时不能输出/防护，在乐园按缺失耐久修复收费。**本次没有耐久磨损、修理、出售和隐藏外观收费**，防止原型经济被未完成系统卡死。

## 7. 世界之源与任务

入队考核清场+2.1%，欧卡区域清场+3.6%，巨虎清场+3.2%，总计8.9%。不是可直接消费的货币，不采用旧版“20源点换属性点”。领取区域战利品时一起保存，重进已清场区域不会再次产出。

烙印展示：国王主线（未完成、本次范围外）；左大臣的藏品（未取得虎齿/已取得待后续交付）。当前阶段状态由stage、cleared、settled表示，退出重进仍保持。小说主线72小时、支线10小时仅保留为后续任务数据设计，本次无真实倒计时/超时惩罚，也不伪造完成任务数量。

下一地区门槛：必须领取本地区战利品；王都入口需开箱取得引荐信；侍卫总部需实际装备斩龙闪；巨虎区域结束后只去阶段结算。无任何1.7之后的剧情跳转。

## 8. 阶段评价与乐园结算

切片临时评价表：猎虎成功且世界之源≥8.9%为A，基础2属性点+1000币；其余成功为B，基础1属性点+600币。当前线性必经流程正常到达的是A，B留作未来允许跳过区域时的降档。不能提前结算。

世界Lv.6减玩家权限等级≥5时奖励×2（按Word定义，包含恰好差5级）。第一轮因此发4属性点+2000币；第二轮Lv.2无双倍。开箱金币独立于评分倍率。该表是阶段测试经济，不是小说国王通关A-的4点/10000币奖励。

结算一次性执行：发奖励 → 权限等级+1 → 清理世界限定物 → 状态转乐园 → 生命免费恢复满 → 自动存档。重复按钮/读档不会再结算。下一次试炼仍是相同切片，不暗示敌人难度已经动态提升。结算后实际进入原灰潮港，可自由走动，在原功能点按V操作。

## 9. 单机乐园设施

复用已经建好的灰潮港作为单机乐园主城，不新建主城地图：

- 属性强化：仅在乐园操作，每点消费1属性点，力量/敏捷/体力/智力可投；没有按等级白送属性。
- 补给：恢复药剂100币/份，余额不足拒绝购买。
- 刀术训练：1000币+灵魂结晶小×1升级一次，近战伤害每级+10%，上限3级。这是切片训练效果，不授予灭法之影刀术专精职业。
- 再次试炼：保留裸装属性、可带出物、装备、钱、训练与永久法力；重置地区、世界之源、击杀集合和单世界法力额度，枪弹6发，生命满。

预留长期规则：专属房间为安全状态，强化大厅负责属性提交，试炼场可接无永久死亡训练，固定商店负责补给。无需模拟其他契约者、职工者、拍卖市场与PVP。

## 10. 恢复与风险

药剂1.2秒饮用，期间停止移动/攻击；受击打断且已消耗药剂不返还。同区域第n次成功饮用回复最大生命的40%/n（被打断也计入使用次数）；没有额外冷却。该比例是原型统一药剂，不套用小说不同食物/XT-12的名称数值。

初始2份；废品终点站再给2份；欢乐街给2份、3个火药陷阱和诱饵。地区间保留剩余生命、弹药和消耗品；饮用递减次数在进入新地区时重置。乐园免费治疗，药剂仍需购买，保证没钱时也能继续试炼。

## 11. 存档与失败恢复

单槽user://save.cfg，向后兼容旧姓名/货币档。旧档缺campaign字段时添加新流程，新档六维采用Word基准。持久化：地区/清场、背包、装备、任务目标、世界之源、永久/世界法力、等级、轮次、弹药、检查点生命和结算报告。

保存时点：建档、领取战利品、开箱、换装、推进地区、乐园服务、再次试炼。战斗/准备中的临时消耗不自动提交；死亡或未领取前退出重进，从上一检查点重新打该区域。完成区域后使用的补给在推进/返回菜单时保存。

原HUD的角色面板、菜单、帮助和服务对话打开时暂停玩家、敌人、波次/猎虎准备与陷阱计时，战斗中背包只读；避免在菜单里继续挨打或换装刷新资源。应用关闭时保留最近已提交检查点，不保证恢复到战斗中的瞬间。

## 12. 当前实现边界与后续接口

已实现：三层循环、五地区、真实动作战斗、巨虎阶段/破腿、目标掉落、开箱、装备效果、世界之源、噬灵者上限、阶段评价、乐园消费强化、存读档、失败重试。

留作后续设计：多任务日志/限时惩罚、任意要害致死、完整耐久、随机装备词条、探索分支、出售经济、训练镜像、完整世界评价E-~S+、职业传承、后续世界。灭法之影/青钢影等只在真正完成对应剧情后解锁；当前不提前发职业或法术。

当前运行时已复用原场景：1.2~1.5使用现有石砌练习场；1.6使用原外围三波、北侧传送门和决战空地；返回原灰潮港。保留地图文件、镜头、光照和遮挡，控制器只对接流程与奖励，不生成新美术。C面板复用原立绘、8槽和64格背包，点击物品后在右侧操作。外围清场保存独立检查点，未击杀巨虎不发1.6奖励。演武场使用原练功木桩，资源与正式存档隔离。

## 13. 验证

运行 tools/validate_core_loop.gd：覆盖新档→五地区→巨虎诈死/破腿→领取→结算→强化补给→再次试炼；同时验证推进门槛、重复领奖、防刷上限、失败回滚、菜单暂停、装备派生、各阶段存读档。测试用独立core_loop_validation.cfg，不覆盖真实存档。战斗流程通过真实场景和伤害接口自动验证；难度与操作手感仍需人工试玩调节。
