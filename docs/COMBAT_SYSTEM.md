## 1. 角色定位与战斗循环

猎杀型刀战角色：侦查拉扯 → 消耗敌人能量 → 抓破绽近身爆发。法力是核心资源，青钢影靠燃烧敌方能量打真实伤害。

```text
侦查评估 → 远程骚扰（右键燧发枪 / R 刀芒）消耗 → 拉扯走位规避 → 寻找窗口 → Space 剃突进贴脸
→ Q 猎魔 → 近战输出（单段斜劈，命中留影刺标记）→ 可 T 影刺爆发
危险时 E 傲歌护盾；法力不足 Q 自动/手动关闭后撤；必要时 1 号键埋/扔炼金炸弹。
```

核心约束：**不无脑硬刚、忌站桩对砍；法力枯竭战斗力暴跌；高威胁优先撤退。**
猎魔/影刺的真实伤害只对**拥有能量**（`has_energy == true`）的敌人生效，纯肉体敌人只吃物理伤害。

### 3.3 回合规则（现状口径）

| 项 | 值 | 来源 |
|---|---|---|
| 先攻（AT） | 敏捷降序；敏捷相同时**玩家先手**；玩家取敏捷，敌人基线 5 | `_rebuild_order` |
| 我方回合 | 先自动走位 `min(移动力, 距离 - 攻击距离)` → 再出五选一指令 | `_auto_approach` / `_player_command` |
| 移动力 | 玩家 `3.0 + (敏捷 - 5) * 0.2`；敌人 `move_speed` | `BattleUnit.from_player / from_enemy` |
| 可攻击判定 | 距离 ≤ `attack_range` + 目标 `hit_radius()` + 0.05 | `_in_attack_range` |
| 指令 | 攻击 / 战技 / 防御 / 道具 / 逃跑 | `_player_command` |
| 战技子页 | 剑气·断空（`sword_wave`）、环断（`ring`）；MP 不足时提示、不空放 | `_player_skill` |
| 道具子页 | 药剂（即时回 `max_hp * 40%`）、炼金炸弹（原地 AoE） | `_player_item` / `battle_execute_item` |
| 防御 | 本回合受伤 **×0.25**；被近战命中时 **30%** 概率弹反而免伤 | `_enemy_command` |
| 侧击 / 背击 | **按目标朝向判定**：`dot(目标朝向, 目标→攻击者) > 0.7` 正面 ×1.0；< −0.45 背击 **×1.25**；其余侧击 **×1.1** | `attack_bonus` · `forward_of` |
| 防御存活期 | 到**该单位自己下次行动开始**为止（`_begin_turn_for` 清）；**不在整轮重排时统一清** | `_begin_turn_for` |
| 敌人回合 | 0.55s 节拍 → 一步接近或攻击：距离 ≤ `attack_reach * 0.9` 返回「攻击」，否则按 `move_speed` 步进（返回「接近」，DUMMY / 已死返回「待机」）；命中伤害取 `attack_damage` | `_enemy_command` · `enemy.battle_advance` |
| 回合回蓝 | 每整轮 **5% 最大 MP（至少 1）**，**替代**野战口径的命中 1% + 被动 0.2%/s | `take_regen_mp` |
| 胜负 | 敌方全灭 → 胜；玩家 `alive == false` → 败；逃跑成功 → 退出战斗（无掉落） | `_run_battle` / `_end_battle` |
| 逃跑 | 我方敏捷 + d10 vs 敌方平均敏捷 + d10 | `flee` |
| 技能数值 | 仍读 `combat_skills.gd`，**不新增帧序列** | — |

> 说明：侧/背击**已按目标真实朝向判定**（09-23 修）：旧实现拿攻击者朝向点乘"攻击者→目标"，而出事前 `_face()` 刚把攻击者拧向目标，点乘恒为 1 → **永远判正面**。玩家读 `facing`，敌人读 `−basis.z`。
>
> **HP / MP 同步口径（09-23 修）**：**玩家实体是唯一权威**。出手后 `pull_player_stats()` 把实体值抄进作战单位；每整轮回蓝结算在单位上，wrap 后 `flush_player_mp()` 抄回实体。收尾**不再**用开战快照覆盖 `player.mp`（那会把回合内花掉的蓝整笔退回）。HP 只作镜像、不写回（敌人出手会在同步点之外改血）。

## 4. 普攻（单段斜劈）与武器伤害

| 项 | 值 | 来源 |
|---|---|---|
| 倍率 | **1.3** × 面板 | `combat_skills.gd COMBO_MULTIPLIERS` |
| 冷却（出手间隔） | **0.6s** | `COMBO_COOLDOWNS`（12 帧 @15fps 片长 0.8s，播放 1.33× 恰好铺满冷却） |
| 命中帧 | **0.12s** | `COMBO_HIT_TIMES` |
| 判定 | 距离 2.5 + 0，弧半角 1.0 rad 前向扇形 | `player.gd attack_range / COMBO_REACH_BONUS / COMBO_ARC_HALF` |
| 输入缓冲 / 朝向 | 0.15s；出手朝向 = 鼠标所指地面方向 | `player.gd` |
| 影刺标记 | **每次命中都留下**刺入标记（窗口 1.25s），保住 T 影刺前置；目标存活时标记 | `_hurt_in_cone → _mark_pierced` |
| 拼刀参与 | 出手后至命中 + 0.3s 内可被拼刀 | `can_clash_now` |

伤害 roll（我方输出链）：

```text
物理伤害 = 双 roll 取平均(武器强化后区间) × 裸装力量倍率 str_atk_coef(力量) × (1 + 0.1 × 刀术训练) × 技能倍率
武器损毁时 roll × 0.5
真实伤害（猎魔 / 影刺）为加法附加：不进倍率、跳过敌人物理减免；护盾照常吸收。
```

- 面板攻击（战役）= 武器区间中点 × `str_atk_coef` ×（1 + 0.1 × 刀术训练）；非战役 = 7 + 力量。
- 强化区间：`attack_min/max + ATTACK_ADD_BY_TYPE[weapon_type] × 强化等级`；`ATTACK_ADD_BY_TYPE = {1h_sword: 1.5, heavy: 2.2, dagger: 0.9, gun: 1.2}`，`ENHANCE_MAX = 12`。
- 力量倍率表 `STR_ATK_COEF_ROWS`：≤5 → 1.00、≤10 → 1.10、≤18 → 1.22、≤30 → 1.35、>30 → 1.45。
- 普攻判定同时扫 `enemies` 与 `targets` 两个组（纯靶子挂 targets，不影响清场判定）。

## 9. 我方受击结算链

```text
已计算: 原始伤害 × (1 − 护甲总减免 armor_reduction，各槽 def_pct 求和 clamp 0~0.9) × 肉体修正 con_hit_factor(体力)   [体力 ± 2%/点，体力5 = 1.00]
↓ 傲歌护盾吸收（先吸盾，余量扣 HP；破盾即碎）
↓ 扣 HP ≤ 0 → 死亡（清标记、闭猎魔、碎盾）
↓ 护甲耐久：实际扣血 ceil(lost/10) clamp(1, 5)，一次命中只扣一件未损毁护甲
```

- 真伤接口预留给敌方侧（跳过物理减免），玩家当前主要受物理伤害；`invulnerable`（剃蓄力段）与护盾先于一切结算。
- 击杀扣武器耐久：`kill_dur(击杀档位 tier)`（1 / 3 / 8 档查表）。
- 药剂饮用与回复过程中吃攻击会被打断；当前不存在面向玩家的真伤来源。
