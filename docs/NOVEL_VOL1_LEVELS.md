## 1. 关卡流程

保留1.2~1.5的顺序和场景复用；每个技能在临近需求时提示，并在对应战斗中完成一次实际动作。燧发枪解锁卡洛斯宝箱，直踹与影刺解锁欢乐街，刀芒与环断解锁科尔波山；未在战斗中完成的技能可在清场后的安全木桩补练。科尔波山准备阶段还需开启傲歌、猎魔并预埋陷阱，三项都完成后才引出巨虎。猎虎结算回港后依次提示成长、补给、工坊、任务档案与可选演武场；整备引导不锁下一轮出发。主菜单“开始新游戏”签订乐园契约后进入；“继续游戏”恢复已提交检查点。

### 1.1 乐园契约
- 纯文本：修复伤势 → 契约登记 → 噬灵者与半数据化说明 → 废品终点站。
- 不包含现实复仇演出，不发放灭法之影职业。

### 1.2 废品终点站
- 进入地区 → V开始 → 观察流民攻击预警与生命值 → 击败后按交互键领取破旧燧发枪、药剂×2 → 打开背包查看药剂。
- 玩家初始普通匕首、药剂×2；WASD移动、鼠标三连、Shift闪避。
- 不做毒气地形、掩体网络或枪战背景。

### 1.3 王都入口
- 进入地区 → 装备并试射新得到的燧发枪 → 击败黑市商人卡洛斯 → 获得白色宝箱、噬灵者+5 → C开箱取得引荐信和120币 → 下一地区。
- 尚未试射时，卡洛斯宝箱保持锁定，并指引先装备燧发枪、完成一枪。
- 未开箱取得引荐信时禁止推进，并给明确提示。
- 不做伪装、气味、对话分支或完整潜行路线。

### 1.4 侍卫总部
- 进入地区 → 与教官进行入队切磋，提示直踹与影刺 → 获得侍卫凭证、斩龙闪、世界之源2.1% → C装备斩龙闪 → 完成直踹与影刺后解锁下一地区。
- 切磋不视为剧情杀人，不发噬灵者。斩龙闪替换普通匕首并提高真实攻击力。
- 不做贿赂经济、仓库地图和多武器选择。

### 1.5 欢乐街
- 进入地区 → 击败欧卡和1名护卫，在双目标战斗中提示刀芒与环断 → 白色宝箱、世界之源3.6%、噬灵者+10/+1 → C开箱获得亡妻项坠和240币 → 装备/补给 → 完成刀芒与环断后直接解锁科尔波山。
- 同时取得药剂×2、火药陷阱×3、木天芷，供猎虎备战；不再切出一段必须完成的技能清单。
- 不做民居、寻声、屋内潜入和暗杀路线；项坠力量+1实际作用于后续战斗。

### 1.6 科尔波山巨虎
- 进入原外围 → V启动三波 → 清场保存 → 北侧原传送门 → 原决战空地 → V启动15秒准备并预埋一枚火药陷阱 → 巨虎登场 → 战斗 → 真正击杀 → V领取虎齿、绿宝箱、世界之源3.2%、噬灵者+15 → 阶段试炼结算。
- 巨虎保留狂暴、诈死/暴起、补刀；绕后近战3次可破坏筋腱减速。诈死不算击杀，不能提前领奖。
- 绿宝箱固定虎爪、灵魂结晶小、400币；可在清场或乐园开启。
- 木天芷作为准备剧情道具，V确认即视为完成诱饵放置，不额外制作诱饵AI；火药陷阱使用踩踏引爆，不实现枪击炸药桶的演出。
- **本次到这里停止剧情**：不交虎齿、不升侍卫首领、不制作路飞/卡普彩蛋。
- 为跑通宏观循环，接游戏化“阶段试炼结算” → 单机乐园属性强化、补给与刀术训练 → 再次挑战相同五个地区。明确标注国王主线未完成，不能冒充完整海贼王通关。

以下1.7~1.13是原著后续规划，未实现、不会从本次主流程进入。

## 5. 本次实现约束

1. 优先验证战斗、领取、成长、推进、结算、强化与再出发；战役前四区在共享战斗宿主上按阶段装配独立空间布景，科尔波山和港口复用既有场景，素材沿用已入库预置。
2. 1.2~1.5为明确的小规模正面战斗，不以旧稿潜行优先要求阻塞本次交付。
3. 血量显示百分比，内部使用可验证的伤害数值；普通要害一击必杀留待后续。
4. 装备和宝箱必须可操作，不能仅展示说明文字；关键门槛失败时告诉玩家缺少什么。
5. 完成一地区领取才提交检查点；死亡回滚未提交的区域收益和消耗，重进已清场地区不能重复刷奖励。
6. 后续剧情表格、敌人、NPC、国王掉落均为预留资料，本次不生成相应关卡。
