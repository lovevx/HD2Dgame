更新：2026-09-28。用F5运行项目，从主菜单“开始新游戏”或“继续游戏”进入。原先独立的地图、HUD、装备面板和主城服务已接入正式流程。

## 试玩顺序

1. 签订乐园契约并完成灰潮港木桩训练后进入废品终点站。开场提示流民预警和生命值；WASD移动，左键斩击，Shift闪避。清场靠近战利品按V领取，人物面板自动打开并显示药剂。
2. 王都入口先在背包装备破旧燧发枪，按鼠标右键试射；受伤时按2使用药剂。击败卡洛斯后按C开白箱取得引荐信；未试射前宝箱会提示先完成枪械练习。
3. 侍卫总部的教官战提示K直踹和斩击命中后的T影刺；两项实际释放后才解锁欢乐街。未在战斗中练完时，清场后会开放安全木桩补练。领取斩龙闪后按C装备，查看攻击属性变化。
4. 欢乐街同时出现欧卡与护卫，提示按R释放刀芒、敌人靠近时按F使用环断。两项都完成后解锁科尔波山；未在战斗中练完时可在清场后的木桩补练。
5. 进入原科尔波山外围。按V启动三波遭遇；清场自动保存外围检查点，走进北侧传送门进入原林间决战空地。外围不给额外世界之源/噬灵者奖励。
6. 决战空地按V启动15秒准备；按1投掷一枚预埋火药陷阱、按E开启傲歌、按Q开启猎魔，三项完成后巨虎才会出现。倒计时结束后若还缺动作，安全准备状态会继续等待；战斗中看红圈预警并用Shift闪避，留意狂暴、诈死与绕后破腿。
7. 真正击杀巨虎并按V领取后，走进北侧返回门触发阶段结算，回到灰潮港主城。不会直接进入国王或后续剧情。
8. 猎虎结算回港先显示评价与奖励，再依次提示分配属性点、查看补给、检查工坊训练、打开任务档案。
9. 任务档案后可自选进入东南演武场练习，也可直接走北侧世界入口开始下一轮。演武场使用临时药剂/陷阱，Esc菜单可返回灰潮港；练习消耗、受伤和死亡均不改正式物资与阶段进度。港口的世界入口和演武场入口走进即传送，服务点仍按V交互。

游戏内教学提示从键位设置实时读取；本表中的按键仅列当前默认值。

C人物面板、Esc菜单、F1帮助和服务对话打开时暂停玩家、敌人与波次/准备倒计时。战斗中背包只读。返回主菜单在Esc菜单内操作；正式战斗中不提供无条件回港跳关。

## 检查点

地区领取战利品、开箱、换装和乐园消费会保存（这些即出击事务的提交点）；外围清场另存内部检查点。未提交的那部分 —— 途中拾取的装备与战斗中扣掉的耐久 —— 在死亡 / 放弃出击 / 异常退出时整体回滚，所以阵亡重试不会出现「战利品留下、耐久不还原」的半提交，也挡掉了「反复阵亡刷掉落」。已经清过外围的旧档直接恢复决战空地；前版已猎虎/结算的存档仍可继续，不要求重开。

> **2026-09-23 修正**：上句的「回滚」此前只是面板文案。装备拾取（`equipment_drop._collect`）与耐久损耗（`game_state.damage_item_dura`）都是即时 `save_game()`，即已提交，回滚无从谈起；只有玩家本地数值（生命/药剂）因为本来就没写进 `campaign` 而看起来像回滚。现在这两处改为只改内存，由 `GameState` 的出击事务（`begin_sortie` / 提交点 / `rollback_sortie`）统一管理，阵亡面板的文案也按「有无未提交改动」如实分叉。四条结束路径（正常撤离 / 逃脱币救援 / 无币永久死亡 / 超时）已收敛到 `settle_sortie(outcome)`；后三条的具体数值与角色销毁仍待拍板，暂都按回滚处理。

正式存档user://save.cfg，另有 .bak 备份档与 version 字段；写入走临时档 + rename 原子替换，正式档损坏回退备份。新增colpo_outer_cleared字段默认false。演武场状态仅存在内存，不写进剧情档。开始新游戏会覆盖单槽进度，继续游戏保留当前档。本局事务与坏档恢复的回归见 `tools/validate_save_transaction.gd`。

## 验证

Godot 4.7.2，隔离存档的`tools/validate_core_loop.gd`覆盖原练习场、64格背包/11槽装备、五地区、分段教学与动作记录、欢乐街直达科尔波山、陷阱准备门槛、外围三波和真实传送、15秒准备/暂停、巨虎机制、资源结算、港口服务碰撞与按钮、演武场往返隔离、再次试炼。`tools/validate_onboarding_flow.gd`覆盖序章教学，`tools/validate_quest_panel.gd`覆盖任务档案。无头及D3D12 Forward+实际渲染通过；原人物面板、外围、决战、港口和工坊截图已查看。自动测试通过伤害接口击败敌人，战斗难度仍需人工试玩调整。
