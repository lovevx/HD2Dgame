# 核心循环试玩与原有内容接入

更新：2026-09-18。用F5运行项目，从主菜单“开始新游戏”或“继续游戏”进入。原先独立的地图、HUD、装备面板和主城服务已接入正式流程。

## 试玩顺序

1. 签订乐园契约后进入废品终点站。V开始遭遇；WASD移动，左键朝鼠标完成斜劈→前刺→重斩三段，第二段命中后可按 T 影刺；Shift闪避。当前战斗系统联调版也可用 Q 猎魔、E 傲歌、R 刀芒、F 环断；技能消耗的 MP 会随检查点跨地区保留。
2. 清场靠近战利品，V领取；C打开原人物面板，在左侧物品格选中宝箱/装备，然后点击右侧“开启宝箱”或“装备”。Esc或C关闭。
3. 王都入口要开启卡洛斯宝箱取得引荐信；侍卫总部要实际装备斩龙闪。欢乐街掉落的项坠可以装备，力量+1。
4. 欢乐街后进入原科尔波山外围。V启动三波遭遇；清场自动保存外围检查点，走进北侧传送门进入原林间决战空地。外围不给额外世界之源/噬灵者奖励。
5. 决战空地V启动原15秒准备；1向鼠标处投掷预埋火药陷阱，倒计时结束巨虎出现。F燧发枪、2饮用药剂；留意狂暴、诈死与绕后破腿。原出口门面在战斗中隐藏，领取战利品后点亮，避免挡住出生点视线。
6. 真正击杀巨虎并V领取后，走进北侧返回门触发阶段结算，回到灰潮港主城。不会直接进入国王或后续剧情。
7. 港口靠近原功能环按V：西侧潮汐杂货买药；东侧铸潮工坊投属性点/消耗结晶训练刀术；西南委托所查看任务和结算报告；东南演武场进入原练功木桩；北侧世界入口开启下一次阶段试炼。
8. 演武场使用临时药剂/陷阱，Esc菜单可返回灰潮港。练习消耗、受伤和死亡均不改正式物资与阶段进度。港口的世界入口和演武场入口走进即传送，服务点仍按V交互。

C人物面板、Esc菜单、F1帮助和服务对话打开时暂停玩家、敌人与波次/准备倒计时。战斗中背包只读。返回主菜单在Esc菜单内操作；正式战斗中不提供无条件回港跳关。

## 检查点

地区领取战利品、开箱、换装和乐园消费会保存（这些即出击事务的提交点）；外围清场另存内部检查点。未提交的那部分 —— 途中拾取的装备与战斗中扣掉的耐久 —— 在死亡 / 放弃出击 / 异常退出时整体回滚，所以阵亡重试不会出现「战利品留下、耐久不还原」的半提交，也挡掉了「反复阵亡刷掉落」。已经清过外围的旧档直接恢复决战空地；前版已猎虎/结算的存档仍可继续，不要求重开。

> **2026-09-23 修正**：上句的「回滚」此前只是面板文案。装备拾取（`equipment_drop._collect`）与耐久损耗（`game_state.damage_item_dura`）都是即时 `save_game()`，即已提交，回滚无从谈起；只有玩家本地数值（生命/药剂）因为本来就没写进 `campaign` 而看起来像回滚。现在这两处改为只改内存，由 `GameState` 的出击事务（`begin_sortie` / 提交点 / `rollback_sortie`）统一管理，阵亡面板的文案也按「有无未提交改动」如实分叉。四条结束路径（正常撤离 / 逃脱币救援 / 无币永久死亡 / 超时）已收敛到 `settle_sortie(outcome)`；后三条的具体数值与角色销毁仍待拍板，暂都按回滚处理。

正式存档user://save.cfg，另有 .bak 备份档与 version 字段；写入走临时档 + rename 原子替换，正式档损坏回退备份。新增colpo_outer_cleared字段默认false。演武场状态仅存在内存，不写进剧情档。开始新游戏会覆盖单槽进度，继续游戏保留当前档。本局事务与坏档恢复的回归见 `tools/validate_save_transaction.gd`。

## 验证

Godot 4.7.2，隔离存档的tools/validate_core_loop.gd覆盖原练习场、64格背包/11槽装备、五地区、外围三波和真实传送、15秒准备/暂停、巨虎机制、资源结算、港口服务碰撞与按钮、演武场往返隔离、再次试炼。无头及D3D12 Forward+实际渲染通过；原人物面板、外围、决战、港口和工坊截图已查看。2026-09-18补充通过原背包格选中和操作按钮实际开箱/装备、主菜单继续游戏恢复港口、北侧原传送门进入第二轮。旧港口独立入口回归检查HUB_RESULT: PASS；正式流程CORE_LOOP_FAILURES=0。自动测试通过伤害接口击败敌人，战斗难度仍需人工试玩调整。
