# P1 垂直切片范围基线

版本：v1.1 · 日期：2026-09-16 · 状态：范围锁定（战斗按键与技能集已按苏晓映射更新）

本文件是 P1 的范围裁决依据。与 [GDD.md](GDD.md)、[COMBAT_SYSTEM.md](COMBAT_SYSTEM.md) 或旧策划提案冲突时，以本文件为准。P1 只证明以下闭环成立：

`主城准备 → 进入灰潮隔离港 → 战斗与情报选择 → 正常撤离 / 逃脱币救援 / 无币永久死亡 → 结算与成长`

## 1. P1 完成交付

### 战斗

- 鼠标点击方向攻击；WASD 只负责移动。
- 动作采用前摇、有效帧、后摇；判定绑定有效帧。
- P1 按键与技能集（v1.1 锁定）：

| 按键 | 功能 |
|---|---|
| W/A/S/D | 移动、战斗奔跑、走位拉扯 |
| 鼠标左键 | 近战三段连击：正手劈砍、反手刺击 |
| 鼠标右键 | 双枪射击，远程物理骚扰，弹药有限 |
| Q | 青钢影・猎魔：开 / 关；燃烧敌人能量造成真实伤害，法力低于 1% 强制关闭 |
| E | 青钢影・傲歌：生成 / 撤销能量护盾，消耗法力，有吸收上限与持续时限 |
| R | 刀芒：远程刀气，中距离消耗，不造成真实伤害 |
| F | 环断：原地环形刀气，处理复数包围，法力消耗偏高 |
| T | 影刺：仅在反手刺击命中后可用，空放无效且不扣法力 |
| Left-Shift | 剃（六式・剃）：地面短距高速位移，有冷却；空中释放判定失败 |
| 数字 1 | 炼金炸弹：投掷输出或地面预埋陷阱，库存有限 |
| 数字 2 | 药剂：回复生命，每局携带量有限 |
| V | 交互：NPC、撤离信标与可交互物 |
| Esc | 面板 / 菜单 |
| 无按键 | 拼刀格挡：双方近战有效帧重叠时自动触发，不占用按键 |
| Tab、鼠标中键 | P1 空置，仅保留给后置的使徒之眼与吞噬之核，不制作功能（注：鼠标中键在 2026-09-19 已用于镜头控制，吞噬之核键位待重新指定） |

- **拼刀格挡（替代原「右键按住防御」）**：双方攻击的有效帧在短窗口内重叠时，判定拼刀，本次攻击双方都不结算伤害，敌人被弹开并进入短硬直，玩家可立即续接下一段；只对近战攻击生效，远程弹道与落点攻击不参与；有短冷却，避免连续刷拼刀。判定窗口、弹开距离、硬直与冷却为待试玩校准的初值。
- **影刺前置**：反手刺击命中敌人后记录“刺入”标记；无标记时按 T 无效且不扣法力。特效在敌人身上，玩家本体不做大幅度挥砍。标记时限与是否持续到目标死亡，实现前确定。
- **青钢影**：Q 是开关状态，开启期间持续消耗法力；对拥有能量的敌人造成真实伤害，对完全无能量的肉体敌人只造成普通物理伤害；法力低于 1% 强制关闭。青钢影不属于奥义或血气系统。
- **法力经济**：法力主要来源是击杀拥有能量的敌人（噬灵者天赋）；击杀纯肉体敌人不回复法力；P1 不投放大量回蓝药剂，法力下限由「关闭青钢影、后撤拉扯」承担。
- **敌人能量属性**：P1 每个敌人必须在数据中标注“有能量 / 无能量”，青钢影与噬灵者对两类敌人的表现必须不同；未标注的敌人不得进入正式遭遇。
- 韧性与破绽：重甲正面高韧、绕背破防；Boss 只在指定破绽可打断。
- 伤害链路：物理伤害、护盾、HP、硬直、致死的完整链路，并新增真实伤害链路（跳过物理护甲，读取真实抗性，不跳过无敌与闪避）。
- 灵魂伤害仍只保留枚举、事件字段和规则测试接口，不制作对应敌人生态、技能和 UI。
- 攻击使用动作前摇、地面危险标记和音效共同预警。

### 世界与关卡

- 手工制作灰潮隔离港：5 个主区域、2 个可选分支；分支不能绕过主线目标。
- 固定房间与固定遭遇池；房间内只随机少量预设敌人组合。
- 前景靠近玩家淡出；危险范围始终显示在前景之上。
- 区域切换和加载过渡；35 分钟世界活动时限按 GDD 规则运行。
- 模块化港区资源重复使用，主要通过灯光和雾效区分区域。
- 简化导航，保留窄门并发限制与卡位自救；不追求复杂群体避障。

### 经济、成长与装备

- 四种成长资源：乐园币、小灵魂结晶、世界之源、灵魂碎片。
- 逃脱币是低价购买的保命消耗品，不属于第五种成长资源。有币死亡消耗一枚、保留角色和存档、本局收益只结算 30%；无币永久死亡。
- 力量、敏捷、体力、智力四维生效；魅力与幸运仅保留存档字段，P1 不参与任何公式、事件或掉落。
- 敏捷只微调移动速度，不改变攻击速度、输入缓冲、剃时长或无敌时间。
- 世界结束时按世界之源结算属性点：每 20% 世界之源兑 1 点，不足 20% 保底 1 点（不设“源点”货币，2026-09-21 定）；刀术 3 节点、天赋“灵魂回响”、称号“灰潮清理者”。
- 武器、护甲、饰品 3 槽；白、绿、蓝 3 品质；8 件固定装备；12 格背包。
- 每件装备使用固定属性和固定被动，不生成随机词缀。
- 强化 +1～+3 必定成功。
- 精英和 Boss 固定掉落基础资源，并提供少量战利品二选一；主城商店固定清单。

### 任务、情报与提示

- 主线、探索支线、可选猎杀悬赏三类任务；主线未完成不能正常撤离，悬赏可以放弃。
- 同一份关键情报可付费购买，也可通过支线侦查获得。
- 直感只使用无方向脉冲与音效，不显示敌人位置。
- 蓝色日志记录契约条件、任务结果和资源变化。
- NPC 使用面板交互；文本集中于目标、代价、期限和风险警告。
- 任务失败仅处理超时和战死两类入口，均进入统一逃脱币/永久死亡裁决。

### 主城与存档

- 主城一个场景、四个面板：契约终端、工坊、补给商、装备房间。
- 独立免费试炼木桩房，与正式资源和任务存档隔离。
- 账户档、角色档、世界实例档分离。
- 正常结算、逃脱币救援与永久死亡使用唯一事务提交，恢复时不得重复发奖、扣币或折损。
- 主城使用白盒碰撞、基础光源和占位 UI；音频只做基础 BGM 与核心战斗提示。

## 2. 明确降级方式

- 普通敌人复用通用受击与死亡动作，但每种攻击仍须有可辨轮廓、前摇和危险范围。Boss 的关键攻击允许独立动作，不受通用动作限制。
- Hitstop 和屏幕震动各只做一个全局强度及开关，不按攻击或敌人分档。
- 命中特效复用粒子模板；每类敌人最多配置 1～2 种，不为每个技能制作独立特效套装。
- 输入缓冲固定 0.15 秒；剃无敌固定 0.15 秒（蓄力段），P1 没有延长无敌时间的装备、属性或天赋。
- NPC 无分支演出；少量世界记录可以直接服务情报，不建立收集系统。
- UI 用基础控件和占位图标，只有规则反馈与可用性属于验收范围。

## 3. P1 禁止新增清单

以下项目即使已预留字段，也不得在 P1 制作玩法、UI、美术或数值内容：

- 血气条、奥义、终极技能（青钢影是开关状态，不属于奥义；吞噬之核后置）。
- 使徒之眼威胁侦查（威胁光点、敌人威胁分级）与吞噬之核读条大招；P1 只空置 Tab 与鼠标中键，不制作面板、数值、表现和敌人标注。
- 灵魂伤害相关的技能、敌人与 UI（只保留枚举、事件字段与规则测试接口）。
- 中毒、流血、麻痹、眩晕等异常状态系统。
- 三阶段及以上 Boss、普通敌人大量组合连招。
- 程序化地图、随机房间拼接、复杂高低差解谜、动态世界事件。
- 随机装备词缀、大型掉落池、动态商店、装备分解与锻造。
- +4 以上强化、掉阶、损毁与保护材料。
- 幸运掉落效果、魅力交涉效果。
- 晋升任务、强制猎杀、多分支失败剧情、长对话演出和日志收集系统。
- 黑市、玩家交易、图鉴/怪物百科功能、高级付费试炼。图鉴可以只有明确标记“P2”的禁用占位按钮，不制作页面、数据和资产。
- 主城房间装饰和可交互摆件。
- 单局临时 Build、完整从者、冒险团、联网 PVP。

预留接口只能包含稳定的枚举、字段或空数据定义。禁止为“以后可能用到”提前制作编辑器、面板、资产管线或完整框架。

## 4. 变更门禁

P1 新增需求只有同时满足以下条件才能进入：

1. 直接修复主循环无法完成、规则无法理解、数据会损坏或战斗不可读的问题。
2. 无法通过调整现有按键与技能集、三类任务、固定装备或现有 UI 解决。
3. 写明新增内容、被替换或删除的同等工作量、验收方式。
4. 更新本文件和 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) 后再开发。

美术更漂亮、内容更丰富、以后可能需要、原著里存在，都不能单独成为 P1 新增理由。

## 5. P1 退出标准

- 新玩家能在无口头指导下从主城准备并进入世界。
- 鼠标攻击方向、有效帧、剃、拼刀格挡、傲歌护盾、青钢影真伤与影刺前置均可被玩家理解并稳定使用。
- 5 主区与 2 分支均可完成，不会绕过主线或产生无法恢复的卡位。
- 付费情报与侦查能提供同一项有效信息，玩家会在时间和币之间做选择。
- 完成主线后可以立即撤离或继续悬赏，两种选择都有合理玩家使用。
- 正常撤离、死亡有逃脱币、死亡无逃脱币、超时四条路径分别通过；救援只保留本局收益的 30%。
- 同一结算事务在提交前、中、后中断并恢复，资源、逃脱币和任务结果各处理一次。
- 8 件装备、3 个刀术节点、1 个天赋和 1 个称号能形成至少两种可辨的准备方案，无随机词缀依赖。
- P1 禁止新增清单中没有已启用功能或待补资产；唯一允许的禁用入口是明确标记“P2”的图鉴占位按钮。
- 形成一份试玩问题清单；未通过项只能属于调参与表现修正，不能是核心闭环缺失。

满足这些条件即可冻结 P1 功能，进入修错、调参与素材替换阶段。

## 6. v1.1 变更记录

本次按用户确认的苏晓映射更新战斗部分，账目如下：

| 类型 | 内容 |
|---|---|
| 新增 | 双枪（右键，弹药）、炼金炸弹（1，库存与预埋陷阱）、青钢影・猎魔（Q，能量敌人与真实伤害）、傲歌护盾（E，吸收上限与时限）、刀芒（R）、环断（F）、影刺（T，刺击前置）、拼刀格挡（无按键）、噬灵者回蓝 |
| 替换 | 晶体防御 → 傲歌护盾（同为法力换容错，重做为主动开关 + 吸收上限 + 时限）；E 技法斩击 → R 刀芒（复用同一套挥刀动作，改为远程刀气） |
| 删除 | 右键按住防御与 MP 吸收格挡、guard 停帧表现，由拼刀格挡与傲歌护盾承担 |
| 键位调整 | 药剂 Q → 数字 2；面板 Tab → Esc；交互 E → V；剃保持 Left-Shift |
| 后置 | 使徒之眼（Tab 空置）、吞噬之核（原鼠标中键空置；中键已改作镜头控制，键位待重新指定） |
| 未变 | 鼠标点击方向攻击、前摇/有效帧/后摇、剃的踩地与冷却规则、韧性破绽、P1 经济与存档范围 |

同等工作量说明：删除的「按住防御 + MP 吸收 + guard 表现」是一整套防御动作与数值，改由成本更低的拼刀（复用现有攻击有效帧、hitstop 与击退）和傲歌护盾（复用现有护盾球）承担；其余九项新增没有等量删除项，**P1 战斗内容为净增**，成本主要落在正式动作资产（E01）与规则验证（[IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) 第 3 节）。因此顺序要求为：先完成 A01 输入重排与 A05 拼刀替换，再依次验证 A06 双枪、A08 青钢影，双枪、炸弹与青钢影不得同时开工。
