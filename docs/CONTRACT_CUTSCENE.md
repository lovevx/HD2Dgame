> 主角：**玩家自建的无名契约者**（沿用 GDD"使用用户自建角色，不另建/替换主角"）

## 0. 定位与红线

### 定位
开场是**"你"的故事**：一个普通人死亡 → 被轮回乐园选中 → 签约成为契约者 → 传送进试炼世界。签约是世界观入口（半数据化、噬灵者、等价交换），不是某个小说主角的个人经历。

### 红线（不做什么）
| 禁止内容 | 原因 |
|---|---|
| 苏晓的刀 / 父母遗物军官刀 / 索刀对白 | 苏晓个人设定，玩家角色没有这把刀 |
| 复仇动机（"我需要力量去复仇"） | 苏晓专属；玩家动机由玩家自己定义 |
| "能复生故去的人？"问答 | 苏晓的执念，与玩家角色无关 |
| 猎杀者清理"异常契约者"的职业说明 | 世界观扩展，开场不需要；留待后续展开 |
| 灭法之影 / 青钢影觉醒 | 苏晓专属天赋；玩家天赋是【噬灵者】（现有设定） |

### 保留的世界观（轮回乐园共通的）
半数据化 · 世界之源 · 衍生位面 · 等价交换 · 契约者/猎杀者身份由乐园判定

## 1. 玩家角色签约演出（替换 opening.gd 中第 7~10 条纯文字提示）

现有 `opening.gd` 的 `LINES` 第 7~10 条是纯文字带过签约：
```
「轮回乐园 · 猎杀者试炼」检测到契约者灵魂强度达标，伤势已修复。
签订契约，开启半数据化与天赋【噬灵者】。从今天起，每一次猎杀都会带来成长。
```

升级为**羊皮纸签约演出**（插在第 6 条"心跳"与取名面板之间），全长约 40 秒：

| # | 时间 | 镜头/画面 | 台词 / 文字 | UI | 输入 |
|---|---|---|---|---|---|

| 6.7 | 9~16s | 蓝字条款逐条浮现（打字机） | 【签约后，你将进入衍生位面，完成乐园发布的任务。】 / 【任务奖励将依据获得的「世界之源」结算。】 / 【详细规则以契约条款为准。】 | 文字浮现 | 无 |

## 2. 羊皮纸契约面板设计（玩家版）

### 2.1 视觉规范（SystemUI 世界观变体）

| 元素 | 值 | 说明 |
|---|---|---|
| 面板底色 | `Color("2b2116")` 深羊皮纸褐 | 替代 BG，保留暗底原则 |
| 内衬底色 | `Color("3d2f1d")` 羊皮纸中褐 | 替代 BG_BLOCK，条款区 |
| 描边 | `Color("c9a35c")` 褪色金 | 替代 BORDER |
| 主高亮 | `Color("ffd98a")` 血金 | 替代 ACCENT，是/否选中 |
| 文字 | `Color("f4efe4")` 暖白（沿用 TEXT） | 正文 |
| 说明字 | `Color("b6ad9b")`（沿用 TEXT_DIM） | 条款说明 |
| 符文 | 金色像素符文（`pixel_block` 思路） | 装饰 |
| 血染 | `Color(0.72, 0.12, 0.10, 0.85)` 暗血红 | 签约瞬间 overlay |

### 2.2 布局（1080p 居中，约 760×560）

```text
┌──────────────────────────────┐
│ ◆ 轮回乐园·契约（金色标题）   │ ← decor() 四角铆钉
│ ┌──────────────────────────┐ │
│ │ 符文装饰行 ▚▞▚▞          │ │
│ │ 【条款·节选】            │ │ ← 只读，可滚动
│ │  · 进入衍生位面，完成任务 │ │
│ │  · 依据世界之源结算奖励   │ │
│ │  · 噬灵者天赋将强制觉醒   │ │
│ │  · 一切都将等价交换       │ │
│ └──────────────────────────┘ │
│    [ ◀ 否 ]   [ 是 ▶ ]       │ ← SystemUI 按钮，默认焦点「是」
│    按 ◀ ▶ 选择 · 回车确认     │
└──────────────────────────────┘
```

### 2.3 交互
- 默认选中「是」；◀ ▶ 切换；回车确认（复用 `style_button` 焦点冰蓝）
- 选「否」：按钮抖动 + 【警告：契约未成立。灵魂消散倒计时仍在继续。】（红字闪烁），不关闭
- 选「是」：血染演出 → 面板褪色 → 取名面板
- 演出期间全部输入锁死（复用 quest_panel 模态冻结口径）

## 4. 与原著的差异（明确标注）

| 原著（苏晓） | 玩家版处理 | 原因 |
|---|---|---|
| 被枪击濒死（小腿击穿） | 现有：车祸（晚高峰路口） | 玩家自己的死亡方式，不复制苏晓 |
| 索要军官刀（父母遗物） | **删除** | 玩家角色没有这把刀 |
| "能复生故去的人？" | **删除** | 苏晓执念 |
| 复仇动机 | **删除** | 玩家动机由玩家自己定义 |
| 灭法之影/青钢影觉醒 | **删除**，只保留蓝芒暗示 → 改为【噬灵者】绑定 | 玩家天赋固定为噬灵者（现有系统） |
| 猎杀者职业说明（清理异常契约者） | **删除**，仅保留"猎杀者"称呼 | 开场不展开职业系统 |
| 半数据化 / 世界之源 / 等价交换 / 羊皮纸契约 | **保留** | 轮回乐园共通世界观，与玩家角色兼容 |
