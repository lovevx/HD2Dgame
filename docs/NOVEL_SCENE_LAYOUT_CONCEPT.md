## 空间叙事结论

小说给出的地理关系很紧凑：废品终点站紧邻哥亚王国城墙；穿过城门后经过废品场，再向外就是科尔波山。场景序列应当让玩家读懂“被王国抛弃的边缘地带 → 城门秩序 → 王国内的权力节点 → 夜间花街 → 山林猎场”的空间与权力变化，而不是把五关做成同一座院子换地表。

空间情绪也应逐关变化：废品场视线杂乱、边界压迫；城门把路线收窄再放开；侍卫总部规整、正面、可读；欢乐街灯火密集但留出战斗通道；山林外围遮蔽、空地决战清晰。灰潮港是游戏循环使用的整备主城，不是哥亚王国的剧情地点，图中单独标为“HUB”。

## 场景落地

- **灰潮港**继续使用 `scenes/world/harbor.tscn` 的南岸码头、中央主街、两侧服务区和北侧出发门。
- **废品终点站 / 王都入口 / 侍卫总部 / 欢乐街**由 `scripts/main/main.gd` 按 campaign stage 装配独立布景：分别加入垃圾通道、城门检查坪、总部前院切磋圈和红灯夜街。建筑沿边布置；围墙与店面选择性启用碰撞，中心战斗路和传送出口保持通畅。
- **科尔波山**继续使用 `scenes/world/colpo_forest_outer.tscn` 与 `colpo_forest_clearing.tscn` 的外围波次和林间空地。
- 场景区分沿用项目已有模型、地面 shader、体积雾和灯光，没有新增外部模型或改写共享原始素材。

| 1.2 废品终点站 | 城墙前的大型垃圾场。用两侧垃圾堆、废车和棚屋围出不规则边界，中间保留连续视线和可闪避的通道；远景放青绿色毒烟与城墙剪影。 | 从远离城门的一端进入，遭遇区置于场地中段，枪械与药剂奖励落在清场后易识别的位置，城门方向作为下一步目标。烟雾只作远景氛围；当前玩法稿不做毒气伤害地形。 |
| 1.3 王都入口 | 黑石高墙和小城门作为强轮廓，墙外道路压缩视野；门后接检查空地，再转入卡洛斯战斗的小型街巷/货场。守卫站门洞两侧，避免把门洞本身变成堵路点。 | 由南向城门推进，试射燧发枪后完成战斗；卡洛斯与白箱形成“敌人 → 奖励 → 引荐信 → 北向出口”的清楚顺序。 |
| 1.4 侍卫总部 | 原文明确为两层办公楼，门前有两名侍卫。楼体靠场地后缘，前方是规整的报到/切磋院；办公室与军械储物间作为后景或侧翼功能房。 | 南侧入口经过门岗后进入中央切磋圈；教官战发生在开阔院心，奖励和斩龙闪放在院边，不让高柜、屋檐遮住角色。这里承担直踹、影刺和换装教学。 |
| 1.5 欢乐街 | 两排楼阁、酒肆/花街招牌与暖色灯笼形成窄街纵深；一栋目标楼阁及其房间/内院是焦点。房顶和檐廊可作为原文“屋顶跟踪”的视觉提示，首版作为不可行走的轮廓。 | 主街保持一条连续可战斗带；欧卡和一名护卫在目标楼阁前后形成双目标遭遇。侧巷只做短支路或背景，不做强制潜行迷宫。 |
| 1.6 科尔波山 | 外围是被树石切分的林间路径，三波遭遇围绕路径和地标展开，北侧传送门连接决战空地。决战空地用环状树幕围住草地，原文的稀疏水源、野花与植被提供诱饵和陷阱的叙事理由。 | 外围战后进门；决战场留出巨虎体型和扑击空间，树丛压在边缘，陷阱点沿周边可读区域分布，准备区靠入口。巨虎体型约4米高、7–8米长，画面中要明显大于角色。 |

## 关卡搭建要点

1. **先定路，再放景。** 每张战斗地图先画入口、遭遇区、奖励点和出口；然后用建筑、岩石和植被框出边界，避免装饰先占满战斗空间。
2. **按镜头留视线。** 项目采用俯视倾斜的 3D/HD-2D 构图。高墙、屋檐、密树适合放边缘或背景；场地中央和角色前方保留低矮轮廓，避免挡住敌人预警、掉落物和出口。
3. **让地标解释玩法。** 城门解释通行门槛；总部院心解释切磋；欢乐街目标楼解释双目标交战；山林空地的花草、水源和环状树幕解释诱饵与陷阱。
4. **场景之间复用材质语言，不复用空间结构。** 沿用项目现有石材、木构、植被、灯具和 HD-2D 光影；每关保留不同的主轮廓、地表节奏和明暗色彩。
5. **控制垂直遮挡。** 欢乐街的屋顶跟踪只通过高低层次暗示，不要求首版制作可走屋顶；山林中央也不摆高树。遮挡问题应在默认出生机位和战斗机位下检查。

## 原著后续场景（本次布局图之外）

小说第 18–22 章还有废品终点站焚城、海贼攻入王都和王宫刺杀。可作为下一阶段的复用改造：废品场复用原路线，把火线设为动态边界并引导逃生；王都以“平民区 → 中心街 → 独立王宫区”分层，城墙与王宫城堡组成最终进攻轴；王宫内部用楼层搜索与破窗离场收尾。项目关卡稿把 1.7 之后标作未实现规划，因此本稿不把它们画进当前可玩主线，也不暗示游戏已经做到焚城或国王战。
