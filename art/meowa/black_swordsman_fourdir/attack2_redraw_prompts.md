# 两段攻击 · Holopix 八方向生成规格（2026-09-20）

直接用 holopix 生成八方向成品。产出 **2 个动作 × 8 方向 × 8 帧 = 16 组动画**。
角色造型基准：`assets/characters/black_swordsman/新版动作/`（跑步/闪避/受击）——白色高领内衬、修长头身比、长款黑风衣、细长太刀。

## 一、动作行为

**一段 · 袈裟斩（下劈）**：单发重斩。双手举刀过顶（起自右肩），拧腰沉胯蓄半拍，然后整条手臂带刀从头顶右上方向左下方劈落，身体前倾压进打击，劈到底后顺势收刀回预备势。气质：**重、沉、蓄力明显**。

**二段 · 逆袈裟（上撩）**：连招第二击，接在一段收势之后。刀已经在左膝旁，不回预备势直接反手从左下往右上撩起，展胸、重心落到后脚，撩过肩膀后顺势落刀收回。气质：**快、轻、借势**——比一段少一帧蓄力。

## 三、八方向表现要点

轨迹定义：一段 = 从角色自身**右上劈向左下**；二段 = 从角色自身**左下撩向右上**。各方向都是同一条轨迹的空间旋转，只换镜头关系：

| 方向 | 镜头关系 | 表现要点 |
|---|---|---|
| down | 正面 | 全身正面可见；一段刀从头顶劈向观众方向，刀光弧罩在身前 |
| down_right | 斜前 45°，面朝右前 | 露左侧脸；一段刀光弧在身体右前侧 |
| right | 正侧面，面朝右 | 刀贴身侧走斜弧；一段收势刀在身体远侧（被躯干部分遮挡） |
| up_right | 斜后 45°，面朝右后 | 大部分露背；刀光弧在画面右前侧 |
| up | 背面 | 全背身；刀在画面深处挥动，刀光弧被躯干遮挡只露两端 |
| up_left | 斜后 45°，面朝左后 | up_right 的朝左版本 |
| left | 正侧面，面朝左 | right 的朝左版本 |
| down_left | 斜前 45°，面朝左前 | down_right 的朝左版本 |

**持刀手约束**：角色始终右手在前双手握刀。生成 left / up_left / down_left 时是"真实的面朝左"，**不是 right 系的镜像**——镜像会出现左手持刀，禁止。

## 四、规则

1. **节奏**：每方向 8 帧、10fps、整段 0.8s。游戏内会约 2 倍速播放，第 4 帧就是伤害判定帧，必须落在刀最舒展的接触瞬间。
2. **衔接**：二段帧 1 的持刀位 = 一段帧 6 的持刀位，两个动作首尾同位，连按看起来是一刀接一刀。
3. **锚点**：8 帧内脚底站在同一位置，画布中脚底点不动（原地攻击，零位移）。
4. **刀光**：只出现在帧 3~6，一段是下落弧、二段是上升弧，同色系深红；两段刀光弧方向必须相反。
5. **命名**：`attack1_方向`、`attack2_方向`；方向名 `down / down_right / right / up_right / up / up_left / left / down_left`。

## 五、约束（禁忌清单）

- **禁止**：位置移动、跳跃、镜头移动或缩放、中途转身变向、帧间人物忽大忽小、出现左手持刀。
- **角色一致性**：8 帧同一角色——黑发、白色高领内衬、长款黑风衣、深色长裤短靴、细长太刀；脸和发型每帧可辨认同一个人。
- **身体幅度**：一段前倾明显但不扑地；二段展胸但不后仰过度；头始终朝目标方向。
- **风衣与头发**：跟随动作惯性摆动，幅度克制——快动作里飘动慢半拍是大忌。
- **刀光**：是叠加特效层，不遮挡脸与躯干轮廓，不把人物整体染红。
- **风格**：与新版动作三件套同颗粒度的干净像素风，透明背景，无背景元素、无地面阴影以外的任何场景物件。
