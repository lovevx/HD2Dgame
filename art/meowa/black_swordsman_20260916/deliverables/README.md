# 黑衣剑士 · Meowa 像素角色

基于玩家概念图生成。保留黑发、高领黑风衣、腰带、长靴、武士刀和红色斩击。此包为单视角动作素材，未替换现有玩家场景，也不包含四方向或八方向动画。

## Godot 导入

使用 AnimatedSprite3D 和 SpriteFrames。通过精灵表添加帧，横向与纵向均设为3，按从左到右、从上到下顺序选择前8格，跳过右下空白格。移动开启 Loop，攻击关闭 Loop。Texture Filter 选择 Nearest，像素预览使用整数倍缩放。

移动朝右，攻击朝左；需要同向时可为其中一种动作设置 flip_h。翻转也会改变持刀手，严格保持左右手时应另行生成对应方向。两种动作画布不同，需要分别调整脚底锚点：移动约(72,125)，攻击约(112,138)，这些是起始帧参考值，不是逐帧自动校准。建议先在 SpriteFrames 预览动作，再校准 Sprite3D 的 offset。

攻击的收尾姿势与首帧不相同，作为单次动作使用；接待机时可加入姿势过渡。现有玩家脚本攻击间隔为0.42秒，若直接接入，可将攻击播放速度调整为约19 FPS，或按游戏设计重新同步伤害时点。
